# OnSori prototype integration contract

Local backend: http://127.0.0.1:8765. Static studio: `/`. Every API request sends `X-OnSori-Client: onsori-local-v1`. CORS supports this origin and chrome-extension:// origins only. No external API key.

Document: `{schema_version:"1.0", video_id:null|string, title:string, duration:number, cues:Cue[], warnings:string[], metadata:object}`. Cue: `{id:string,start:number,end:number,text:string,kind:"speech"|"sound"|"music",dbfs:number|null,relative_db:number|null,scale:number,confidence:number|null,source:string,review_required:boolean,details?:string,words?:{start:number,end:number,text:string}[]}`. Seconds are absolute video time. scale range .75–1.55. Treat all text as plain text. Validate finite times, duration, enum and string limits on import. Never inject HTML.

Optional `Cue.volume_profile`: `[{time:number,dbfs:number,scale:number}]`, maximum 12002 points. Times use absolute video seconds, are strictly ascending, and stay within the cue ±0.05s rounding tolerance. All numbers must be finite, dBFS −120..12, scale .75..1.55. Omitted or empty profiles preserve legacy per-cue scale. Null is invalid. Analysis samples RMS every 0.1s with a shared recording reference and fast attack/slow release; profile time receives start_time exactly once.

Render `cue.scale`, calculated from the RMS of the entire cue interval against the recording reference. Apply effectStrength and baseSize, then responsive fit. Playback time and `volume_profile` do not change font size within a cue. Profiles remain available for diagnostics and JSON export; timing edits trim/interpolate their boundary points. SRT/VTT export only text and timing.

`metadata.music_analysis[cue.id]` preserves selected AST tags (label, Korean text, score), rhythm evidence and source. Scores are heuristic gates, not calibrated accuracy. Unsupported attributes are null/empty; do not infer a song title, mood or instrument from generic music presence. `metadata.volume_profile_method` documents the dynamics method. Existing schema_version 1.0 documents remain readable.

GET `/api/health`: `{status:"ok",version:"0.1.0",models:{whisper:boolean,events:boolean,captioning:boolean},message:string}` (boolean = dependency available, not model weights loaded).
POST `/api/jobs/youtube` JSON `{url,language:"ko",whisper_model:"base",event_detection:true,audio_captioning:false}` -> Job. YouTube transcript preferred; audio downloaded for sound + volume. Errors remain visible, never substitute demo.
POST `/api/jobs/upload` multipart `file`, `options` JSON same options plus `{video_id:null|string,title:string,start_time:0}` -> Job. `start_time` shifts uploaded recorded interval to original video timeline. File max 100MB, duration max 20min.
GET `/api/jobs/{id}` -> `{id,status:"queued"|"running"|"done"|"error"|"cancelled",progress:0..1,message,result:Document|null,error:string|null}`.
DELETE `/api/jobs/{id}` -> cancellation request. One analysis at a time. Poll every 1.5–2s, stop when terminal.
GET `/api/demo` -> explicitly labelled demo Document (no audio recognition claim).
POST `/api/export/{format}` JSON Document -> attachment; formats json,srt,vtt. SRT/VTT don't preserve dynamic font sizes; JSON does.
POST `/api/validate` JSON Document -> validated normalized Document.

Source layout: extension/ (Manifest V3 popup, worker, offscreen, content), web/ (studio), server/ (API and inference), scripts/, tests/, docs/.
Extension design: YouTube watch/shorts video overlay tied to video.currentTime; fullscreen resize; SPA video change clears mismatched captions. Global settings storage; captions per video in storage.local with bounded cache; enabled/showSpeech/showSound/showMusic/infoLevel simple|standard|rich/effectStrength 0|.5|1/baseSize 14 (8..28), typographyVersion 2, autoAnalyze true/offset seconds. Recompute on seek/pause/play/ratechange. Use textContent and isolated styles, hide only native CC while overlay active and restore when off. Import/export JSON. Extension popup controls URL analysis, import, open studio, and explicit current-tab capture as offline interval analysis (NOT fake real-time). Capture from toolbar gesture via tabCapture + offscreen Chrome116+, preserve playback audio. Stop on navigation/seeking/rate !=1 or paused, use exact interval start, cap at60s, no microphone. Upload captured WebM as multipart from offscreen; show capture state and job progress, then store result under video_id and send to tab. Never auto navigate or auto-play user video. Handle absent server and actionable errors.
Studio: polished accessible Korean UI with file/video input, job progress, review/edit cues incl times/type/text, filters, local preview video, waveform-style timeline (real volume data or clearly a timeline, no invented waveform), demo clearly marked, import/export JSON/SRT/VTT, volume info and caption typography preview. No build dependencies preferable, vanilla modules, no CDN, no API secrets. Include keyboard and focus states, reduced motion.


2026-10-25 UX update: legacy baseSize values are halved once on normalization, marked typographyVersion=2. Shared extension/studio core renders old cached music failure phrases as neutral music descriptions. Unsupported instruments/mood remain empty in metadata; no fabricated detail.

Automatic flow: foreground, playing, non-ad, finite <=20min video -> one URL attempt per tab/video -> on failure or transcript-only results, 60s tab capture while playback is 1x. Browser invocation is still required for tabCapture; a real toolbar popup can clear a permission wait, even while paused, for later playback. Cache coverage includes analyzed silence. Busy/cancelled/disabled/background states suppress starts; failed capture windows are not repeatedly retried. Offline health checks back off 30s. Cancelling suppresses auto work for that video, manual actions remain available. No auto seek after completion and no claim of streaming transcription.

Completion gate: cache entries carry `displayVersion:1`, `ready:boolean`, `origin:analysis|import`. Starting a new analysis atomically sets that video's previous entry to ready=false with the operation state. Errors and cancellation do not restore it. Validated final results and operation=done are published in one storage write. Partial/transcript-only job results are not published. Same-video busy operations suppress display and GET_STATE document access. Legacy entries lacking the marker remain stored but hidden and are excluded from range merges; automation can retry once without overriding user cancellation/permission waits. Import is explicit, marks a document ready and is rejected during analysis. Cache markers represent completed processing, not verified ASR correctness.

AnalysisOptions.use_caption_references defaults true. caption_references is a list of <=2000 {video_id,start,end,text,source:'youtube-native-caption'}, absolute video seconds, each <=15s and <=500 chars. Upload ASR jobs also fetch original-language human captions. Exact source text is applied only with conservative timestamp and lexical agreement; no generated grammar correction; screen OCR is described below. Optional Cue.speech_correction retains original_text/source/words, corrected_text, reference source/video/times, similarity and word_timing_status. Corrected cue words are cleared because original word timings no longer describe displayed text. Metadata and JSON export preserve provenance.


Screen correction: screen_frames is <=241 video-bound {video_id,time,jpeg} lower-video JPEG crops, <=350000 chars each. PaddleOCR runs locally in an isolated subprocess; >=0.94 recognition confidence and >=2 repeated observations required. If pixels are unavailable, a public <=720p source video is attempted, with no browser cookie access. Complete OCR spans align against up to 3 ASR cues using time, character and Hangul-jamo agreement. Partial sentences must not delete unseen speech. Cue.speech_correction.reference_source also accepts youtube-screen-ocr; original text/words are retained and volume is averaged across merged cues. Display cache version is now 2, invalidating previous uncorrected caches.
