# 온소리 자막 in YouTube

YouTube 영상의 **대사·음악·효과음**을 함께 읽고, 구간의 평균 음량을 자막 크기로 표현하는 Chrome 확장 프로그램입니다. 대사는 YouTube 자동 자막이 있으면 그 자막을 대사로 쓰고, 없으면 기기 안에서 음성 인식으로 만듭니다. 효과음 위치와 글자 크기는 이 기기에서 계산합니다.

**현재 버전은 0.4.1입니다.** [Chrome 웹 스토어](https://chromewebstore.google.com/detail/faoookmndmicfapakdnelnepfdcphgkp)의 공개 버전은 0.4.0이고(2026-11-16 업데이트), 0.4.1은 2026-11-17에 심사 제출해 **검토 대기 중**입니다. 승인되면 자동으로 게시되고, 이미 설치한 확장도 Chrome이 알아서 업데이트합니다.

## 주요 기능

- 대사·효과음·배경음악을 같은 자막에서 구분해 표시합니다. 효과음은 `♪ 문 닫히는 소리 ♪`, 배경음악은 `♬ 피아노 연주 ♬`처럼 적습니다.
- 구간의 평균 음량을 글자 크기로 보여 줍니다. 한 대사나 효과음이 표시되는 동안에는 크기가 고정됩니다.
- 재생 위치부터 1분씩 분석해 **끝난 구간의 자막을 바로** 표시하고, 영상별로 저장해 다시 분석하지 않습니다.
- 대사는 YouTube 자동 자막을 먼저 쓰고, 받지 못하면 기기 음성 인식으로 만듭니다.
- 선택 기능: 동의하면 서버를 거쳐 Google Gemini가 음악 설명과 효과음 이름을 붙이고, AI가 대사 오타를 고칩니다.
- 별도 프로그램이나 API 키 없이 시작할 수 있고, 마이크는 쓰지 않습니다.

## 설치

1. [Chrome 웹 스토어](https://chromewebstore.google.com/detail/faoookmndmicfapakdnelnepfdcphgkp)에서 **Chrome에 추가**를 누릅니다.
2. YouTube 영상에서 도구 모음의 퍼즐 아이콘 → **온소리 자막 in YouTube**를 엽니다. 패널은 영상 오른쪽에 붙고, 창이 좁으면 영상 아래에 표시됩니다.
3. 패널의 **기기 내 분석 사용 설정**을 한 번 누릅니다. 첫 분석 때 기기에서 쓸 공개 AI 모델을 내려받으며(음성 인식 모델은 GPU를 쓰는 PC 약 740MB, CPU만 쓰는 PC 약 170MB) 진행 상태가 패널에 표시됩니다.
4. 서버가 클라우드 소리 분석을 제공하면 패널에 선택 카드가 나옵니다. **클라우드로 분석**과 **이 기기에서만 분석** 가운데 하나를 고르면 분석이 시작되고, 고르기 전에는 자동 분석이 기다립니다(0.4.1부터).
5. 재생 위치가 있는 1분 구간부터 분석해 끝난 구간의 자막을 바로 표시하고, 전체가 끝나면 **자막으로 다시 보기**로 처음부터 확인합니다. 영상을 재생하지 않아도 분석은 시작됩니다.

Chrome 116 이상과 인터넷, 분석에 쓸 만큼의 메모리가 필요합니다.

### 소스에서 직접 불러오기

개발자 모드(`chrome://extensions` → **개발자 모드** → **압축해제된 확장 프로그램을 로드합니다**)로 불러올 수도 있습니다. **이 저장소 `main`의 소스는 아직 0.3.10이고 0.4.x 소스는 `release/0.3.7` 브랜치에 있습니다.** 0.4.x는 GitHub 릴리스 ZIP으로 배포하지 않았으므로 압축해제 설치용 ZIP은 [v0.3.10 릴리스](https://github.com/NY-colab/onsori-youtube/releases/tag/v0.3.10)까지입니다.

## 대사

- **YouTube 자동 자막 우선:** 재생 중인 플레이어가 자막을 표시할 때 보낸 요청 주소를 페이지에서 읽어, 확장이 같은 주소로 그 영상의 자막을 받아 대사로 씁니다. 이때 기기 음성 인식은 실행하지 않습니다. 자막이 꺼져 있으면 재생 중 잠깐 켰다가 보던 사람의 원래 설정으로 되돌립니다.
- **기기 음성 인식:** 자동 자막을 받지 못하면(자막이 없는 영상, 아직 재생되지 않아 플레이어가 자막을 요청하지 않은 경우 등) 기기 안에서 음성 인식으로 대사를 만듭니다. 이때는 같은 시각의 YouTube 자막을 참조해 근거가 충분한 문장만 교정하고, 참조가 없는 대사는 임의로 고치지 않습니다.
- **탭 녹음에서는** 표시 중인 자막을 참조하며, **화면 자막 참조**를 켜면 영상에 박힌 자막도 화면 글자 인식으로 읽습니다.
- **AI 자막 보정(선택):** 패널의 **AI로 대사 오타 보정**을 켜면, YouTube 자막으로도 교정하지 못한 인식 대사의 오타를 AI 언어 모델이 고칩니다. 보내는 것은 인식한 대사 글자, 영상 제목, 바로 앞 대사 몇 줄뿐이고 소리와 화면 이미지는 보내지 않습니다.
  - PC에 온소리 연결 프로그램(Chrome 네이티브 메시징 호스트)이 설치되어 있고 Claude Code에 로그인되어 있으면, API 키 없이 그 계정의 Claude Haiku로 보정합니다. 사용량은 그 Claude 계정에 포함됩니다.
  - 연결 프로그램이 없으면 온소리 서버가 운영자의 DeepInfra API 키로 DeepSeek V4 Flash에 보정을 요청합니다.
  - 확장 설정 화면에서 본인의 Anthropic API 키를 등록해 이 기기에서 Anthropic API로 바로 보낼 수도 있습니다. 요금은 그 키의 계정에 부과됩니다.
  - 원문과 크게 다른 고쳐 쓰기나 소리 표기를 넣은 응답은 받아들이지 않고, 고친 대사의 원문은 자막 JSON의 `ai_correction`에 남깁니다. 요청이 실패하면 인식한 원문을 그대로 표시합니다.

## 음악과 효과음

- **기본은 기기 분석:** 기기의 음향 분류(AST AudioSet) 결과로 악기·음악 특징과 한국어 소리 표현을 만듭니다. 효과음은 `♪ 문 닫히는 소리 ♪`, 배경음악은 `♬ 피아노 연주 ♬`처럼 표기합니다.
- **클라우드 소리 분석(선택):** 동의한 경우에만 영상 전체 분석의 소리를 30초 조각으로 온소리 서버에 보내고, 서버가 Google Gemini API(Gemini 4 Hydrogen)에서 음악 설명과 효과음 이름을 받아 옵니다. 받은 음악 설명은 기기 분석의 음악 묘사를 대신하고, 효과음은 기기가 찾은 시각에 Gemini가 들은 이름을 붙입니다. 효과음의 위치와 글자 크기는 계속 이 기기에서 계산하며, 대사는 이 응답에서 가져오지 않습니다.
- 사용 한도에 닿거나 서버를 쓸 수 없으면 그 뒤 구간의 음악·효과음은 기기 분석 결과로 표시합니다. 그 밖의 실패는 그 1분 구간에만 영향을 줍니다.
- 곡명·가수를 식별하거나 모든 소리를 분리하는 기능은 아닙니다. 확인된 특징이 없으면 일반적인 배경 음악 묘사를 씁니다.

## 글자 크기와 자막 모양

- 자막 크기는 기본 14px에 **구간 평균 음량**을 반영합니다. 한 대사나 효과음이 표시되는 동안 크기는 고정되고, 크기 변화 강도를 조절할 수 있습니다. 기준 음량은 구간별이 아니라 영상 전체의 중앙값을 쓰므로 구간이 바뀌어도 같은 크기의 소리는 같은 크기의 글자로 보입니다.
- **자막 디자인**에서 테마 6가지(온소리 기본, 방송 자막, 고대비, 외곽선, 영화관, 밝은 상자)를 고르고 굵기·글자 색·외곽 효과·배경을 하나씩 바꿀 수 있습니다. 글꼴은 Google Fonts의 한글 지원 38종 가운데 고르거나 다른 글꼴 이름을 직접 넣을 수 있습니다.
- **크기 · 위치 · 파일**에서 X·Y 위치(영상 안 자막 중심의 백분율, 가장자리에서 잘리지 않게 보정)와 표시 종류를 조절하고, 자막을 JSON으로 내보내거나 가져옵니다.

## 1분 구간 분석과 영상별 저장 (0.4.0부터)

- 영상 전체 오디오를 받은 뒤 **1분씩 나눠 분석**하고, 구간이 끝날 때마다 그 구간의 자막을 바로 표시합니다. 재생 위치가 있는 구간을 먼저, 그다음 뒤쪽 구간, 앞쪽 구간 순서로 진행하며 탐색하면 다음 구간부터 새 재생 위치를 따라갑니다.
- 구간 경계는 목표 시각 앞뒤 8초 안에서 가장 조용한 0.2초 지점으로 옮기고, 각 구간은 앞뒤 1.5초를 더 듣고 분석합니다. 경계에 걸쳐 두 구간에서 겹쳐 인식한 대사는 더 긴 쪽 하나만 남기고, 경계를 넘어 이어지는 음악·효과음 자막은 하나로 합칩니다.
- 진행 상태는 `자막 준비 02:00/12:30 · 02:00–03:00 구간 · …`처럼 준비된 길이와 분석 중인 구간을 보여 줍니다.
- 자막은 **영상별로 저장**합니다. 최근 최대 60개 영상, 약 40MB까지 보관하고 오래된 영상부터 지웁니다(Chrome 저장소 기본 한도 10MB를 넘기기 위해 `unlimitedStorage` 권한을 씁니다). 0.3.x의 묶음 저장은 처음 실행할 때 영상별 저장으로 옮깁니다.
- 분석 중 새로고침해도 분석을 취소하지 않고 이어 가며, 새로고침한 페이지는 저장된 구간의 자막을 바로 표시합니다. 다른 영상으로 이동하면 멈추고, 그 영상으로 돌아오면 남은 구간만 이어서 분석합니다. 직접 취소했거나 오류로 멈춘 영상은 자동으로 이어 가지 않고, 패널의 **남은 구간 이어서 분석**으로 계속합니다.
- **새 영상마다 전체 자막 자동 분석** 스위치를 끄면 자동 분석 없이 패널 버튼으로만 시작합니다. 자동 분석은 실패하거나 취소된 영상을 스스로 다시 시도하지 않습니다.

## 0.4.1에서 달라진 점

- 새로 설치해 클라우드 사용을 아직 고르지 않았을 때, 자동 분석이 먼저 기기에서 끝나 그 영상에 Gemini 음악·효과음 분석이 쓰이지 않던 문제를 고쳤습니다. 이제 서버가 클라우드 분석을 제공하고 선택이 비어 있으면 자동 분석이 기다리고, 패널에서 고르면 그 분석이 바로 시작합니다.
- 권한과 데이터 처리 내용은 0.4.0과 같습니다.

## 탭 녹음 (보조 수단)

전체 분석이 어렵다면 **다른 방법 · 분석 설정**에서 **현재부터 최대 60초 녹음**을 직접 선택할 수 있습니다. 자동으로 대체되지는 않으며, 도구 모음에서 온소리를 열어 탭 권한을 연결한 뒤 1배속으로 재생해야 합니다. 녹음은 그 구간만 분석하고, 이미 분석해 저장한 구간은 그대로 둡니다.

## 제한과 알아둘 점

- 전체 분석은 **20분·100MB 이하이고 YouTube가 직접 오디오 주소를 제공하는 일반 영상**에서 지원합니다. 라이브 방송은 지원하지 않고, 주소가 없거나 YouTube가 요청을 제한하면 전체 분석을 시작하지 않으며 자동으로 녹음하지도 않습니다. 서명 해독·DRM 우회는 하지 않습니다.
- 실시간 동시 자막이 아니라 분석이 끝난 구간부터 보여 줍니다. PC 성능에 따라 처리 시간이 달라지고, CPU만 쓰면 수 분이 걸릴 수 있습니다.
- 음성 인식·음악 분류·화면 글자 인식에는 오류가 있을 수 있습니다. 효과음이 난 시각은 짧은 분석 창과 음량으로 추정합니다.
- DRM 등으로 화면 픽셀을 읽을 수 없는 영상에서는 화면 자막 교정을 쓸 수 없고, 일반 Picture-in-Picture에는 페이지 자막이 표시되지 않습니다.
- 0.3.3은 실제 Chrome에서 6분 1초 영상의 전체 오디오 수집·분석·119개 자막 표시를 영상 일시정지 상태로 확인했습니다. 모든 영상의 지원이나 인식 정확도를 보장하지는 않습니다. [검증 기록과 남은 문제](docs/direct-audio-032.md)를 확인하세요.

## 개인정보

- **기본:** 받은 전체 오디오나 탭 녹음, 선택한 화면 자막 이미지는 기기 안에서 분석합니다. 마이크는 요청하지 않습니다.
- **클라우드 소리 분석(선택):** 동의한 경우에만 영상 소리를 30초 조각으로 온소리 서버(네이버 클라우드, 한국)로 보냅니다. 음악 설명과 효과음 이름은 서버가 운영자의 키로 Google Gemini API(Gemini 4 Hydrogen, 미국)에 요청하고, 서버의 대사 분석이 켜져 있으면 대사는 외부 AI 업체 DeepInfra(미국)에서 인식합니다. 서버는 받은 소리를 저장하지 않고 설치별·서버 전체 하루 사용 시간만 기록하며, 분석이 끝나면 소리를 지우고 대사 결과는 24시간 뒤 지웁니다. 동의는 **다른 방법**에서 언제든 끌 수 있고, 끄면 소리를 외부로 보내지 않습니다.
- 0.4.0에서 음악·효과음 전송이 더해져 **동의를 다시 묻습니다**. 0.3.x에서 대사 분석에 동의했던 선택은 이때 새 동의로 이어지지 않습니다.
- **AI 자막 보정(선택):** 위에 적은 대사 글자·영상 제목·앞 대사 몇 줄만 보내고 소리와 화면 이미지는 보내지 않습니다. 전송처는 이 PC의 Claude Code 또는 본인 Anthropic API 키(Anthropic, 미국)와 온소리 서버(DeepInfra, 미국)이며, 온소리 서버는 대사 글자를 저장하지 않습니다.
- **모델과 글꼴:** 최초 모델 다운로드는 Hugging Face와 GitHub의 모델 파일 호스트를 이용하고, 웹 글꼴을 고른 경우에만 Google Fonts에서 그 글꼴을 받습니다. 실행 JS·WASM은 확장 안에 들어 있습니다.
- 저장은 Chrome 확장 저장소에만 하며, 자막은 최근 최대 60개 영상·약 40MB입니다. 광고·추적·통계 전송·개인정보 판매가 없습니다.

자세한 항목은 [개인정보 안내](docs/privacy-browser.md)에 있습니다.

## 업데이트와 권한

- 웹 스토어에서 설치했다면 Chrome이 자동으로 업데이트합니다. 0.4.0에서 `unlimitedStorage`(설치 경고가 없는 권한)와 `nativeMessaging`이 늘었고, 업데이트할 때 Chrome이 ‘협력하는 네이티브 애플리케이션과 통신’ 권한을 한 번 표시하므로 승인해야 확장이 다시 켜집니다. 연결 프로그램이 없는 PC에서는 이 권한으로 아무것도 실행하지 않습니다.
- 압축을 푼 폴더로 설치했다면 **새 ZIP 받기 → 기존 확장 폴더에 내용물 덮어쓰기 → 온소리 카드 ⟳ → YouTube F5** 순서입니다. ⟳만으로는 GitHub의 새 파일을 내려받지 않습니다. 기존 확장을 삭제할 필요는 없습니다.

## 개발과 스토어 제출

```powershell
npm ci --prefix browser-build --ignore-scripts
node scripts/build_browser.mjs
node --test extension/*.test.mjs web/review.test.mjs
python scripts/package_store.py
```

Node.js와 Python은 위 개발·패키징 과정에만 사용합니다. 배포 ZIP은 확장 파일만 담으며 원본 영상·녹음·개발 프로필·Python 서버를 포함하지 않습니다. 0.4.x 브랜치에서는 여기에 `native-host/*.test.mjs` 검사가 더해집니다. [스토어 제출 자료](docs/webstore-submission.md)의 준비 결과는 실제 심사·공개 상태와 구별해서 읽어 주세요.

클라우드 소리 분석을 제공하는 온소리 서버의 계획과 운영 절차는 [추가 업데이트 계획](docs/cloud-update-plan.md)과 [운영 절차](deploy/cloud/RUNBOOK.ko.md)에 있고, 2026-11-04 파일럿 서버 연결 결과는 [파일럿 서버 검증](docs/cloud-pilot-verification-2026-11-04.md)에 있습니다.

이 저장소의 `server/`, `web/`, 기존 Windows 설치 스크립트는 이전 로컬 스튜디오의 개발 자료로 남아 있습니다. **현재 브라우저 확장에서는 호출하지 않습니다.** 기존 Windows 설치형이 필요한 경우 [v0.1.1 릴리스](https://github.com/NY-colab/onsori-youtube/releases/tag/v0.1.1)의 고정 파일과 해당 태그의 안내를 사용하세요. 현재 소스로 구형 설치 프로그램을 다시 만들지 마세요.

Whisper, Transformers.js, AST/AudioSet, Tesseract.js 등 공개 소프트웨어와 모델을 사용합니다. **YouTube 또는 Google의 공식 제품이 아닙니다.** 문의와 문제 신고는 [GitHub Issues](https://github.com/NY-colab/onsori-youtube/issues)로 받습니다.
