# 온소리 자막 in YouTube

YouTube의 대사·음악·효과음을 함께 읽고, 구간의 평균 음량을 자막 크기로 표현하는 Chrome 확장 프로그램입니다. **0.3.0은 브라우저 안에서 분석합니다. Python, 별도 프로그램, 운영 서버, API 키가 필요하지 않습니다.**

**Chrome 웹 스토어는 아직 미제출입니다.** 아래 ZIP은 개발자 모드에서 설치하거나 스토어 심사에 제출할 수 있는 패키지입니다. 스토어 승인·공개 후에는 이 페이지에 공식 설치 링크를 추가합니다.

## 설치와 시작

1. [브라우저 전용 확장 ZIP](https://github.com/NY-colab/onsori-youtube/releases/download/v0.3.0/OnSori-Chrome-WebStore-0.3.0.zip)을 받아 압축을 풉니다.
2. Chrome에서 `chrome://extensions` → **개발자 모드** → **압축해제된 확장 프로그램을 로드합니다** → 압축을 푼 폴더를 선택합니다.
3. YouTube 영상에서 퍼즐 아이콘 → **온소리 자막 in YouTube** → **기기 내 분석 사용 설정**을 누릅니다. 처음에는 공개 AI 모델 수백 MB를 내려받습니다.
4. 기본은 **영상 전체 분석**입니다. 재생하지 않아도 전체 오디오를 분석한 뒤 완성된 자막을 한 번에 표시합니다. **자막으로 다시 보기**로 처음부터 확인합니다.

Chrome 116 이상과 인터넷, 모델 실행에 충분한 메모리가 필요합니다. 전체 분석은 **20분·100MB 이하이고 YouTube가 직접 오디오 주소를 제공하는 영상**에서 지원합니다. 주소가 없거나 YouTube가 요청을 제한하면 전체 분석을 시작하지 못할 수 있습니다. 서명 해독·DRM 우회는 하지 않습니다. **이 버전의 실제 YouTube 전체 오디오 수집부터 자막까지는 미검수**이며, 코드 테스트와 격리 UI 렌더 검수를 마쳤습니다.

영상 옆 패널의 첫 화면에는 전체 분석·진행 상태를 표시합니다. **다른 방법 · 분석 설정**을 펼쳐 최대 60초 **탭 녹음**을 선택할 수 있습니다. 녹음은 자동 대체되지 않으며, 도구 모음의 온소리를 열어 권한을 연결한 뒤 사용합니다. **자막 모양 · 파일 관리**에서 크기, X·Y 위치, 표시 종류와 JSON을 관리합니다. X·Y는 영상 내 자막 중심 좌표의 백분율이며 가장자리에서는 자막이 잘리지 않게 보정합니다.

자동 분석은 처음 사용 설정한 뒤 새 영상마다 전체 오디오를 한 번 시도합니다. 실패·취소 후에는 자동 반복하지 않고 버튼으로 다시 시도할 수 있습니다. 좁은 화면에서는 패널이 영상 아래에 표시됩니다. 업데이트 후에는 확장 관리 화면과 YouTube 페이지를 각각 새로고침합니다.

## 자막의 동작

- **대사:** Whisper로 인식합니다. 전체 분석은 제공되는 원래 자막을 대조합니다. 탭 녹음에서는 표시 중인 자막과 대조하고, **화면 자막 참조**를 켜면 영상에 박힌 자막도 Tesseract로 읽습니다. 반복 관찰과 신뢰도·시간·문장 일치 조건을 통과한 경우만 교정하며, 인식 원문과 출처를 JSON에 남깁니다. 참조가 없는 대사를 임의로 문법 수정하지 않습니다.
- **음악과 효과음:** AST AudioSet 분류 결과로 악기·음악 특징과 한국어 소리 표현을 만듭니다. 확인된 세부 특징이 없으면 일반적인 배경 음악 묘사를 사용합니다. 곡명·가수를 식별하거나 모든 소리를 분리하는 기능은 아닙니다.
- **안정적인 크기:** 기본 14px에 구간 평균 음량을 반영합니다. 한 대사나 효과음이 표시되는 동안 크기는 고정되며, 크기 변화 강도를 조절할 수 있습니다. 혼합 오디오의 상대 RMS이므로 겹친 음악도 영향을 줍니다.
- **완료 후 표시:** 녹음·분석 중에는 온소리 자막을 숨기며, 분석 결과가 완성된 뒤 한 번에 반영합니다. 전체 분석은 일시정지·탐색과 무관하게 진행합니다. 영상 변경·취소 시 임시 작업을 중단합니다. 탭 녹음은 일시정지·탐색 시 그 구간까지만 분석합니다.
- **저장:** 최근 최대 8개 영상의 자막을 용량 한도 안에서 캐시합니다. JSON 내보내기·가져오기와 영상별 삭제를 지원합니다.

대사·음악·효과음 인식에는 오류가 있을 수 있습니다. 효과음 시각은 짧은 분석 창과 음량으로 추정합니다. DRM 등으로 화면 픽셀을 읽을 수 없는 영상에서는 화면 자막 교정을 사용할 수 없습니다. 일반 Picture-in-Picture에는 페이지 DOM 자막이 표시되지 않습니다.

## 개인정보와 공개 구성

받은 전체 오디오 또는 탭 녹음과 선택한 영상 자막 이미지는 기기 내 메모리에서 분석합니다. 운영자의 서버나 외부 AI API로 보내지 않으며, 마이크를 요청하지 않습니다. 최초 모델 다운로드는 Hugging Face와 GitHub의 모델 파일 호스트를 이용합니다. JS·WASM 실행 코드는 확장 안에 포함되어 있습니다.

## 개발과 스토어 제출

```powershell
npm ci --prefix browser-build --ignore-scripts
node scripts/build_browser.mjs
node --test extension/*.test.mjs web/review.test.mjs
python scripts/package_store.py
```

Node.js와 Python은 위 개발·패키징 과정에만 사용합니다. 배포 ZIP은 확장 파일만 담으며 원본 영상·녹음·개발 프로필·Python 서버를 포함하지 않습니다. [스토어 제출 자료](docs/webstore-submission.md)와 ZIP 검증 결과는 실제 심사·공개 상태와 구별합니다.

이 저장소의 `server/`, `web/`, 기존 Windows 설치 스크립트는 이전 로컬 스튜디오의 개발 자료로 남아 있습니다. **현재 브라우저 확장에서는 호출하지 않습니다.** 기존 Windows 설치형이 필요한 경우 [v0.1.1 릴리스](https://github.com/NY-colab/onsori-youtube/releases/tag/v0.1.1)의 고정 파일과 해당 태그의 안내를 사용하세요. 현재 소스로 구형 설치 프로그램을 다시 만들지 마세요.
