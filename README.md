# 온소리 자막 in YouTube

대사, 음악, 효과음을 함께 읽고 소리의 상대적인 크기를 글자 크기로 표현하는 Chrome 확장 프로그램 + 로컬 자막 스튜디오 프로토타입입니다. `[마이 AI 랩] 소리모이` 활동계획서 최종 PDF의 정보량 3단계, 표현 강도 조절, 검수 흐름을 반영했습니다.

## 다운로드

**[Windows용 온소리 ZIP 바로 다운로드](https://github.com/NY-colab/onsori-youtube/releases/latest/download/OnSori-prototype-0.1.0.zip)** · [릴리스와 변경 사항](https://github.com/NY-colab/onsori-youtube/releases/latest)

ZIP을 먼저 압축 해제하세요. 처음 설치하는 PC에서는 아래 **다른 Windows PC에 설치** 절차로 `uv`와 Node.js를 준비한 뒤 `Install-OnSori.cmd`를 실행합니다. 이후 `Start-OnSori.cmd`를 실행하고 Chrome에 `extension` 폴더를 등록합니다. Chrome 웹 스토어 자동 설치 파일이 아니라 로컬 서버와 함께 사용하는 Windows 프로토타입입니다. 모델은 첫 분석 시 별도로 내려받습니다.

## 설치 후 시작

1. **`Start-OnSori.cmd`**를 실행합니다. 스튜디오 주소는 **http://127.0.0.1:8765** 입니다.
2. Chrome 주소창에 **`chrome://extensions`**를 입력하고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 안의 **`extension`** 폴더를 선택합니다. ZIP 파일 자체를 선택하지 마세요.
4. YouTube 영상 페이지를 새로고침하고 확장 프로그램 목록에서 **온소리 자막 in YouTube**를 고정합니다.
5. 영상 오른쪽 추천 목록 위에 **온소리 패널**이 자동으로 표시됩니다. 처음 구간 녹음을 사용할 때는 **Chrome 도구 모음의 온소리 아이콘**을 한 번 직접 누르세요. 팝업을 닫아도 패널은 유지됩니다.
6. **영상을 재생하면 자동 분석을 시작합니다.** 20분 이하 일반 영상에서 URL 전체 분석을 먼저 시도하고, 접근이 제한되면 현재 탭의 최대 60초 녹음으로 이어집니다. 녹음 권한이 필요하다는 안내가 나오면 도구 모음의 온소리 아이콘을 한 번 누르세요. 녹음 버튼은 다시 누를 필요가 없습니다. 자동 녹음은 1배속 재생에서만 시작하며, 자막이 있는 구간은 재사용합니다.
7. 완료된 자막은 자동 적용됩니다. 이미 지나간 녹음 구간은 **자막으로 다시 보기**로 확인합니다. **재생할 때 자동으로 자막 만들기**를 끌 수 있고, **이 구간 다시 분석**으로 수동 녹음도 가능합니다. 취소하면 그 영상의 자동 작업은 다시 시작하지 않습니다. 자동 모드는 재생을 강제로 시작하거나 완료 후 재생 위치를 바꾸지 않습니다.

**패널 사용**: 위쪽 `⌃`로 접고 **온소리 자막 펼치기**로 다시 엽니다. 좁은 화면과 영화관 모드에서는 영상 아래로 배치합니다. 일반 화면에서는 영상 위 진행 안내를 중복 표시하지 않습니다. 전체 화면·Shorts·패널을 접은 경우에는 기존 영상 위 안내를 사용합니다. 자막은 계속 영상 안에 표시됩니다. 다른 YouTube 영상으로 이동하면 패널도 해당 영상으로 갱신됩니다.

**분석 옵션 · 영상 전체 분석**을 펼치면 음성 언어, 상세 소리 설명, URL 기반 전체 분석을 선택할 수 있습니다. 전체 분석은 기존 스크립트를 우선 사용하고, 없으면 Whisper로 대사를 인식합니다. 음악·효과음·음량은 오디오에서 분석합니다. YouTube가 URL 접근을 제한하면 기본 구간 녹음을 사용하세요.

현재 탭 오디오와 영상 하단의 자막 이미지를 수집하며 마이크는 사용하지 않습니다. 화면 이미지는 동영상 픽셀만 읽고 브라우저 주소창·댓글·다른 창은 수집하지 않습니다. 실시간 자막 방식이 아니라 **녹음 후 분석하는 방식**입니다. 광고가 끝난 뒤 시작하세요. 일시정지·탐색·배속 변경·버퍼링·새로고침·다른 영상 이동 시에는 시간축이 어긋나지 않도록 녹음을 종료합니다. 버퍼링이 잦으면 안정적으로 재생된 뒤 구간을 나누어 녹음하세요. 입력 신호가 여러 차례 작게 측정되면 영상·탭 음소거 확인 안내가 표시됩니다. 조용한 장면에서도 나타날 수 있으므로 자동으로 음소거를 해제하거나 녹음을 취소하지는 않습니다.

이미 설치한 상태에서 소스가 수정됐다면 `chrome://extensions`의 **온소리 자막 in YouTube → 새로고침(⟳)**을 한 번 누른 뒤 YouTube 페이지도 새로고침합니다. 재설치나 전체 권한 허용은 필요하지 않습니다. 서버가 꺼져 있으면 패널과 팝업에 **Start-OnSori.cmd 실행 → 다시 확인** 안내가 표시됩니다. 설정과 JSON 파일 관리는 **자막 모양 · 파일 관리** 안에 있습니다.

전체 종료는 **`Stop-OnSori.cmd`**입니다. 이 프로그램이 기록한 서버 프로세스만 종료합니다. 분석 중 종료하면 해당 작업은 다시 시작해야 합니다.

## 다른 Windows PC에 설치

- Chrome 116 이상, 인터넷, 여유 디스크 공간과 메모리가 필요합니다. CPU 실행을 기본으로 하며 NVIDIA GPU는 필수가 아닙니다.
- `uv`가 없다면 PowerShell에서 `winget install --id astral-sh.uv -e`로 설치하고 새 터미널을 엽니다.
- YouTube URL 분석에는 Node.js도 사용합니다. 없다면 `winget install --id OpenJS.NodeJS.LTS -e`로 설치하고 서버를 새로 실행하세요. 로컬 파일 분석에는 필요하지 않습니다.
- **`Install-OnSori.cmd`**: Python 3.10 격리 환경과 고정 버전 의존성을 설치합니다.
- **`Install-Detail-Captions.cmd`**: 선택 기능인 CoNeTTE의 별도 환경을 설치합니다. 서로 다른 PyTorch 버전 충돌을 피하려고 분리했습니다.
- **`Start-OnSori.cmd`** 실행 후 위 Chrome 로드 절차를 진행합니다. 첫 분석에서는 공개 모델을 다운로드하므로 시간이 걸립니다. 상세 묘사에는 추가 모델과 번역 모델이 필요합니다. 용량·기기 성능에 따라 수 GB 이상 공간을 확보하세요.
- ZIP에는 소스만 포함됩니다. 가상환경, 모델, 사용자의 분석 오디오, 신청서 원본은 포함하지 않습니다.

## 자막 스튜디오

- **YouTube URL / 파일 업로드**: 최대 **100MB · 20분**. WAV, MP3, M4A, MP4, WebM, OGG, FLAC, AAC, MOV를 받습니다. 음악만 있는 파일도 분석할 수 있습니다.
- **음성 언어**: 한국어 / 자동 감지 / 영어. CLI에서는 다른 Whisper 언어와 모델 크기도 지정할 수 있습니다.
- **상세 소리 설명 추가**: CoNeTTE가 소리를 문장으로 묘사하고 OPUS-MT가 한국어로 번역합니다. 영어 원문은 JSON `metadata.captioning`에 보존됩니다. 자동 번역의 표현이 어색하거나 의미가 틀릴 수 있으므로 펼쳐지는 상세 설명 편집란에서 검수하세요.
- **음악의 특징**: 기본 분석에서도 악기·장르·분위기·보컬과 규칙적인 박자를 확인합니다. 예: `♪ 트럼펫 연주`, `♪ 피아노 연주 · 규칙적인 박자가 이어짐`. 확인된 특징은 구체적으로 쓰고, 세부 특징을 구분하기 어려운 구간에는 `♪ 배경 음악이 이어짐` 또는 측정된 크기를 붙인 문구를 표시합니다. 분석의 불확실성은 검수용 JSON에 남기며 시청 자막에는 실패 문구를 넣지 않습니다. 곡명·가수를 찾는 기능은 아닙니다.
- **대사 교정**: faster-whisper 인식 뒤 youtube-transcript-api의 같은 언어 제작자 자막, 녹음 중 관찰한 YouTube 화면 CC를 대조합니다. 영상 ID·시각·문자열이 충분히 일치할 때 원본 자막 문구로 교체하고, 인식 원문과 교정 출처를 JSON에 보존합니다. 임의의 문법 재작성은 하지 않습니다. 참조가 없거나 어긋나면 원문을 유지합니다. 영상에 박힌 화면 자막은 PaddleOCR의 한국어 PP-OCRv5로 읽습니다. 높은 신뢰도로 반복 관찰한 문장을 시각·글자·한글 자모로 대조하며, ASR가 문장을 나눠 인식했어도 연결해 교정합니다. 띄어쓰기는 원래 대사와 정렬해 복원합니다. 화면 캡처가 제한되면 공개 원본 영상 접근을 시도하고, 참조 확보 실패 시 추측으로 교정하지 않습니다.
- **편집**: 시작·종료 시각, 대사/효과음/음악 유형, 문구, 상세 설명, 검토 완료를 수정합니다. 자막 추가·삭제·되돌리기를 지원합니다.
- **검토용 원본 연결**: 저장한 JSON을 가져온 후 원본 영상/오디오를 연결해 기존 자막과 대조합니다. 파일이 다른 버전이면 싱크가 달라질 수 있습니다.
- **간결하게 / 기본 / 자세하게**: 간결한 모드는 대사와 소리 종류만 표시합니다. 자세한 모드에서는 상세 설명과 검토 필요 표시를 추가합니다.
- **글자 크기·표현 강도·자막 지연**: 기본값은 14px(이전 28px의 절반), 설정 범위는 8~28px입니다. 기존에 저장한 사용자 크기도 버전 표시와 함께 한 번만 절반으로 옮깁니다. 대사·효과음·음악 **구간 전체의 평균 음량(RMS)**으로 크기를 정하고 해당 구간이 표시되는 동안 유지합니다. 순간적인 소리 변화로 글자를 키우거나 줄이지 않습니다. 구간 간 크기 차이를 강하게, 부드럽게, 고정으로 조절합니다. 화면 크기와 긴 자막에 필요한 맞춤 축소는 유지합니다. 지연값 `+`는 자막을 늦게 표시합니다.
- **완료 후 표시**: 녹음·업로드·분석 중에는 온소리 자막을 숨깁니다. 새 분석을 시작하면 예전 결과도 숨기며 실패·취소·페이지 새로고침 뒤에 되살리지 않습니다. 오디오 분석 없이 받은 스크립트만으로 자막을 자동 표시하지 않습니다. 이번 업데이트 이전 캐시는 보존하되 자동 표시·병합에서 제외하고, 자동 분석이 켜져 있으면 새 분석을 시도합니다. 사용자가 직접 가져온 JSON은 명시적으로 선택한 문서로 표시합니다. 분석 완료는 인식 정확성 보장이 아니며 원본 대조·검토가 필요할 수 있습니다.
- **JSON**은 음량·글자 배율·검토 정보를 보존합니다. **SRT / WebVTT**는 일반 플레이어용 텍스트와 타이밍을 저장합니다. 두 형식에는 동적 글자 크기가 없으며 동시에 나오는 대사와 효과음은 한 자막 블록으로 합칩니다.
- 로컬 파일 자막을 YouTube에 연결하려면 **문서 제목 · YouTube 연결**에서 동일한 영상의 11자리 ID를 지정하고 JSON 저장 → 해당 영상의 확장 팝업에서 JSON 가져오기를 합니다. 영상 길이와 시작 지점이 같아야 합니다.
- 편집 내용은 브라우저 메모리에 있습니다. 창을 닫기 전에 JSON을 저장하세요. 스타일 설정은 브라우저에 남습니다. 데모는 수동으로 작성한 기능 체험용이며 실제 분석 결과가 아닙니다.

## 작동 방식

```text
YouTube 스크립트 / URL 오디오 / 탭 녹음 / 로컬 파일
  → PyAV 16kHz mono → faster-whisper (대사·단어 시각)
  → PyTorch AST AudioSet (소리 유형·악기·장르·분위기) + librosa (박자 근거)
  → 선택: CoNeTTE (소리 문장) → OPUS-MT (한국어)
  → 0.1초 RMS·영상 기준 상대 dB·크기 변화 완화 → 0.75–1.55배 글자
  → 검수 가능한 JSON → YouTube 오버레이 / SRT / WebVTT
```

표시 시각은 `video.currentTime`에 맞춥니다. 일반 재생·탐색·배속·YouTube 페이지 전환을 추적하고 광고 중 오버레이를 숨깁니다. 온소리 대사가 표시되는 구간에만 원래 YouTube CC를 숨겨 중복을 줄입니다. Chrome의 일반 영상 Picture-in-Picture는 페이지 DOM 자막을 표시하지 않습니다.

## 프로토타입의 범위

- AST는 2초 창의 **분류 모델**입니다. 효과음 시각은 음량으로 보정한 추정값이며, 겹치는 모든 소리를 분리하거나 정확한 발생 원인을 확정하지 못합니다. 의성어는 모델의 분류 결과와 한국어 표현표로 만듭니다.
- 음량·강세 표시는 **혼합 오디오 RMS의 변화**입니다. 대사에 음악이 겹치면 음악이 글자 크기에 영향을 줄 수 있습니다. 단어의 의미·억양·감정을 이해한 강조나 사람별 음원 분리는 구현하지 않았습니다. 조용한 영상 전체를 작게 만드는 절대 음압 측정도 아닙니다.
- 악기·분위기 점수는 확률로 보정된 정확도가 아닙니다. 대사가 음악을 가리거나 음악이 짧으면 구체적인 특징을 확인하지 못할 수 있습니다. 박자 추정은 충분한 타격음 근거가 있을 때만 표시하고, 대사 점수가 높은 구간은 박자 분석을 생략합니다.
- 생성형 소리 묘사와 번역에는 오인식·환각·오역이 있을 수 있습니다. 분석 자막은 기본적으로 검토 필요입니다. 소규모 기능 검증으로 일반 정확도 80% 같은 수치를 주장하지 않습니다.
- YouTube 접근 정책, 지역/계정/연령/DRM/라이브 조건에 따라 URL 추출이 실패할 수 있습니다. 로그인 쿠키를 자동으로 가져오지 않습니다. 탭 녹음 또는 접근 가능한 로컬 파일을 사용하세요.
- 정식 Chrome 웹 스토어 배포, 서버 클라우드 배포, 사용자 대상 접근성 실증은 포함하지 않습니다.

## 데이터와 권한

서버는 `127.0.0.1:8765`에만 바인딩합니다. 원본 오디오와 자막 이미지를 외부 AI API로 보내지 않습니다. 공개 모델 다운로드 및 YouTube URL 요청에는 인터넷을 사용합니다. 확장 권한은 storage, activeTab, tabCapture, offscreen과 YouTube/로컬 서버 연결입니다.

업로드·녹음 원본과 결과는 **`runtime/jobs/`에 자동 삭제 없이 보관**됩니다. 서버를 종료한 후 필요 없는 작업 폴더를 사용자가 지울 수 있습니다. 확장은 최근 8개 영상 자막을 용량 한도 내에서 저장하며 팝업의 **이 영상의 자막 지우기**로 제거합니다. 모델 캐시는 `models/`, 설치 환경은 `.venv/`, `.venv-caption/`입니다.

## 개발·검증

```powershell
.venv/Scripts/python.exe -m pytest tests -q
node --test extension/*.test.mjs web/review.test.mjs
.venv/Scripts/python.exe -m server.cli INPUT.wav --output runtime/my-analysis --language ko --captions
```

`--captions`를 빼면 기본 대사·효과음·음량 분석을 수행합니다. `--no-speech`, `--no-events`, `--model small` 옵션도 사용할 수 있습니다. 모델 파일이 준비된 이후 로컬 파일 분석은 외부 AI API 키 없이 실행됩니다.
