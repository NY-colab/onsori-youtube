# 온소리 자막 in YouTube

YouTube의 대사·음악·효과음을 함께 읽고, 구간의 평균 음량을 자막 크기로 표현하는 Chrome 확장 프로그램입니다. **0.3.10은 기본으로 브라우저 안에서 분석합니다. Python, 별도 프로그램, 운영 서버, API 키가 필요하지 않습니다.**

**최신 버전은 [v0.3.10 릴리스](https://github.com/NY-colab/onsori-youtube/releases/tag/v0.3.10)의 ZIP으로 설치합니다.** [Chrome 웹 스토어](https://chromewebstore.google.com/detail/faoookmndmicfapakdnelnepfdcphgkp)의 공개 버전은 0.3.3이며, 이후 버전은 심사 대기 중입니다.

**소스의 0.4.0**은 영상 전체를 1분씩 나눠 재생 위치부터 분석하고, 끝난 구간의 자막을 바로 표시하며 영상별로 저장합니다.<br>선택 기능으로 AI가 대사 오타를 고칩니다.<br>이 PC에서 로그인한 Claude Code나 본인의 Anthropic API 키가 있으면 Claude Haiku로, 없으면 온소리 서버를 거쳐 DeepInfra의 공개 언어 모델로 보정합니다.<br>0.4.0 ZIP은 아직 릴리스하지 않았습니다. 변경 내용은 [0.4.0 변경 사항](docs/release-0.4.0.md)에 있습니다.

## 기존 사용자 업데이트

클라우드·n8n·Grafana 연동은 [추가 업데이트 계획](docs/cloud-update-plan.md)과 [운영 절차](deploy/cloud/RUNBOOK.ko.md)에 정리했습니다. 2026-11-04 운영자 파일럿 서버 연결 결과는 [파일럿 서버 검증](docs/cloud-pilot-verification-2026-11-04.md)에 있습니다. 현재 브라우저 확장의 기본 분석 방식은 기기 내 분석 그대로입니다.

[0.3.10 업데이트 안내](docs/update.md): **새 ZIP 받기 → 기존 확장 폴더에 내용물 덮어쓰기 → 온소리 카드 ⟳ → YouTube F5**. ⟳ 버튼만으로 GitHub의 새 파일을 내려받지는 않습니다. 기존 확장을 삭제할 필요는 없습니다.

## 설치와 시작

1. [브라우저 전용 확장 ZIP](https://github.com/NY-colab/onsori-youtube/releases/download/v0.3.10/OnSori-Chrome-WebStore-0.3.10.zip)을 받아 압축을 풉니다.
2. Chrome에서 `chrome://extensions` → **개발자 모드** → **압축해제된 확장 프로그램을 로드합니다** → 압축을 푼 폴더를 선택합니다.
3. YouTube 영상에서 퍼즐 아이콘 → **온소리 자막 in YouTube** → **기기 내 분석 사용 설정**을 누릅니다. 처음에는 공개 AI 모델 수백 MB를 내려받습니다.
4. 기본은 **영상 전체 분석**입니다. 재생하지 않아도 전체 오디오를 분석합니다. 0.4.0부터는 1분 구간이 끝날 때마다 자막을 표시합니다. **자막으로 다시 보기**로 처음부터 확인합니다.

Chrome 116 이상과 인터넷, 모델 실행에 충분한 메모리가 필요합니다. 전체 분석은 **20분·100MB 이하이고 YouTube가 직접 오디오 주소를 제공하는 영상**에서 지원합니다. 주소가 없거나 YouTube가 요청을 제한하면 전체 분석을 시작하지 못할 수 있습니다. 서명 해독·DRM 우회는 하지 않습니다. 0.3.3은 실제 Chrome에서 6분 1초 영상의 전체 오디오 수집·분석·119개 자막 표시를 영상 일시정지 상태로 확인했습니다. 모든 영상의 지원이나 인식 정확도를 보장하지는 않습니다. [검증 기록과 남은 문제](docs/direct-audio-032.md)를 확인하세요.

영상 옆 패널의 첫 화면에는 전체 분석·진행 상태를 표시합니다. **다른 방법 · 분석 설정**을 펼쳐 최대 60초 **탭 녹음**을 선택할 수 있습니다. 녹음은 자동 대체되지 않으며, 도구 모음의 온소리를 열어 권한을 연결한 뒤 사용합니다. **자막 모양 · 파일 관리**에서 크기, X·Y 위치, 표시 종류와 JSON을 관리합니다. X·Y는 영상 내 자막 중심 좌표의 백분율이며 가장자리에서는 자막이 잘리지 않게 보정합니다.

자동 분석은 처음 사용 설정한 뒤 새 영상마다 전체 오디오를 한 번 시도합니다. 실패·취소 후에는 자동 반복하지 않고 버튼으로 다시 시도할 수 있습니다. 좁은 화면에서는 패널이 영상 아래에 표시됩니다. 업데이트 시에는 먼저 새 파일을 기존 설치 폴더에 덮어쓰고, 확장 관리 화면의 온소리 카드 ⟳와 YouTube 페이지를 각각 새로고침합니다.

## 자막의 동작

- **대사:** Whisper로 인식합니다. 전체 분석은 제공되는 원래 자막을 대조합니다. 탭 녹음에서는 표시 중인 자막과 대조하고, **화면 자막 참조**를 켜면 영상에 박힌 자막도 Tesseract로 읽습니다. 반복 관찰과 신뢰도·시간·문장 일치 조건을 통과한 경우만 교정하며, 인식 원문과 출처를 JSON에 남깁니다. 참조가 없는 대사를 임의로 문법 수정하지 않습니다.
- **음악과 효과음:** AST AudioSet 분류 결과로 악기·음악 특징과 한국어 소리 표현을 만듭니다. 확인된 세부 특징이 없으면 일반적인 배경 음악 묘사를 사용합니다. 곡명·가수를 식별하거나 모든 소리를 분리하는 기능은 아닙니다.
- **안정적인 크기:** 기본 14px에 구간 평균 음량을 반영합니다. 한 대사나 효과음이 표시되는 동안 크기는 고정되며, 크기 변화 강도를 조절할 수 있습니다. 혼합 오디오의 상대 RMS이므로 겹친 음악도 영향을 줍니다.
- **1분 단위 표시(0.4.0):** 전체 분석은 오디오를 받은 뒤 재생 위치가 있는 1분 구간부터 분석하고, 구간이 끝날 때마다 그 자막을 바로 표시합니다.<br>구간 경계는 조용한 지점으로 옮기고, 경계에 걸친 대사는 한 번만 남깁니다.<br>탐색하면 다음 구간부터 새 재생 위치를 따라갑니다.<br>탭 녹음은 이전처럼 녹음 구간 분석이 끝난 뒤 한 번에 반영합니다.
- **저장(0.4.0):** 자막을 영상별로 저장하고, 전체 분석은 1분 구간마다 저장합니다.<br>분석 중 새로고침해도 분석이 이어지고, 다른 영상으로 이동하면 멈췄다가 돌아오면 남은 구간만 분석합니다.<br>직접 취소한 영상은 자동으로 이어 가지 않으며 **남은 구간 이어서 분석**으로 계속합니다.<br>최근 최대 60개 영상을 약 40MB 안에서 보관합니다(`unlimitedStorage`).<br>JSON 내보내기·가져오기와 영상별 삭제를 지원합니다.
- **AI 자막 보정(선택, 0.4.0):** 원래 자막으로 교정하지 못한 대사의 오타를 AI 언어 모델이 고칩니다.<br>설정할 것이 없습니다. PC에 저장소의 `Install-Claude-Bridge.cmd`로 연결 프로그램(Chrome 네이티브 메시징 호스트)을 한 번 설치해 두면, 그 PC에서 로그인한 Claude Code CLI의 Claude Haiku(`claude-haiku-5-5`)로 API 키 없이 자동 보정합니다.<br>연결 프로그램이 없는 PC에서는 온소리 서버(`POST /v1/corrections`)가 운영자의 DeepInfra API 키로 DeepInfra 모델(기본 `deepseek-ai/DeepSeek-V4-Flash-0731`)에 보정을 요청합니다.<br>서버와 DeepInfra는 대사 글자를 저장하지 않으며, 서버는 설치별·서버 전체 하루 줄 수 한도를 둡니다(`ONSORI_CORRECTION=deepinfra`, `DEEPINFRA_API_KEY`, `ONSORI_CORRECTION_MODEL`). 로그인 계정을 바꾸려면 터미널에서 `claude auth login`으로 다시 로그인합니다.<br>**Anthropic API 키**는 키를 등록해 쓰며, 계정을 바꿀 때는 새 키를 저장합니다.<br>인식한 대사 글자만 보내고 소리는 보내지 않습니다.<br>원문과 크게 다른 고쳐 쓰기는 받아들이지 않고, 고친 대사의 원문은 JSON의 `ai_correction`에 남깁니다.<br>요청이 실패하면 인식한 원문을 그대로 표시합니다.

대사·음악·효과음 인식에는 오류가 있을 수 있습니다. 효과음 시각은 짧은 분석 창과 음량으로 추정합니다. DRM 등으로 화면 픽셀을 읽을 수 없는 영상에서는 화면 자막 교정을 사용할 수 없습니다. 일반 Picture-in-Picture에는 페이지 DOM 자막이 표시되지 않습니다.

## 개인정보와 공개 구성

받은 전체 오디오 또는 탭 녹음과 선택한 영상 자막 이미지는 기기 내 메모리에서 분석합니다. 운영자의 서버나 외부 AI API로 보내지 않으며, 마이크를 요청하지 않습니다. 클라우드 대사 분석에 동의한 경우만 소리를 온소리 서버로, AI 자막 보정을 켠 경우만 인식한 대사 글자를 Anthropic(이 PC의 Claude Code 또는 본인 API 키)이나 온소리 서버를 거쳐 DeepInfra로 보냅니다. 최초 모델 다운로드는 Hugging Face와 GitHub의 모델 파일 호스트를 이용합니다. JS·WASM 실행 코드는 확장 안에 포함되어 있습니다.

## 개발과 스토어 제출

```powershell
npm ci --prefix browser-build --ignore-scripts
node scripts/build_browser.mjs
node --test extension/*.test.mjs web/review.test.mjs native-host/*.test.mjs
python scripts/package_store.py
```

Node.js와 Python은 위 개발·패키징 과정에만 사용합니다. 배포 ZIP은 확장 파일만 담으며 원본 영상·녹음·개발 프로필·Python 서버를 포함하지 않습니다. [스토어 제출 자료](docs/webstore-submission.md)와 ZIP 검증 결과는 실제 심사·공개 상태와 구별합니다.

이 저장소의 `server/`, `web/`, 기존 Windows 설치 스크립트는 이전 로컬 스튜디오의 개발 자료로 남아 있습니다. **현재 브라우저 확장에서는 호출하지 않습니다.** 기존 Windows 설치형이 필요한 경우 [v0.1.1 릴리스](https://github.com/NY-colab/onsori-youtube/releases/tag/v0.1.1)의 고정 파일과 해당 태그의 안내를 사용하세요. 현재 소스로 구형 설치 프로그램을 다시 만들지 마세요.
