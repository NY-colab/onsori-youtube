소리를 읽는 세 가지 단계

  1. 영상 또는 오디오를 불러오세요.

    YouTube URL 또는 최대 100MB · 20분의 로컬 파일을 분석합니다. 로컬 서버와 모델이 필요합니다.

  2. 소리와 대조하며 검토하세요.

    대사·음악·효과음 감지에는 오류가 있을 수 있습니다. 각 자막의 시간과 문구, 접어 둔 상세 소리 설명을 편집하고 검토 체크를 켜 주세요. 저장한 JSON을 가져온 뒤 ‘검토용 원본 연결’로 원본 파일을 대조할 수 있습니다. 음량은 dBFS와 상대적인 글자 배율로 표현됩니다.

  3. 나에게 맞게 저장하세요.

    JSON은 음량·크기·검토 정보를 유지합니다. SRT와 VTT는 일반 자막 텍스트와 시간만 담습니다. YouTube 확장 프로그램은 영상 ID가 일치하는 JSON을 적용합니다.

데모는 기능을 보여주는 예시이며 실제 오디오 분석 결과가 아닙니다. YouTube 분석만으로 원본 영상이 스튜디오에 재생되지는 않습니다. 재생 가능한 로컬 파일이 없으면 자막 시간만 미리 봅니다.
