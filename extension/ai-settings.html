보내는 정보

  • 분석이 끝난 1분 구간마다 인식한 대사 글자, 영상 제목, 바로 앞 대사 몇 줄을 보정에 쓰는 AI 서비스로 보냅니다.
  • 영상의 소리와 화면은 보내지 않습니다.
  • Claude Code 연결은 이 PC의 Claude Code가 그 로그인 계정으로 Anthropic에 보내며, 도구·훅·MCP·대화 기록 저장을 모두 끄고 실행합니다.
  • Claude Code 연결이 없으면 온소리 서버(네이버 클라우드, 한국)를 거쳐 DeepInfra(미국)의 공개 언어 모델로 보냅니다.
    서버는 이 설치의 무작위 열쇠로 요청을 받고 대사 글자를 저장하지 않습니다.
    DeepInfra는 요청 내용을 디스크에 저장하거나 학습에 쓰지 않는다고 밝히고 있습니다.
  • API 키는 이 Chrome의 확장 저장소에만 보관하며, 온소리 운영 서버로 보내지 않습니다.
  • AI가 고친 대사는 원래 인식 결과와 함께 자막 JSON에 기록합니다.
  • 보정 요청이 실패하면 인식한 원문 그대로 자막을 표시합니다.
