온소리자막 in YouTube사용 방법

개인정보 안내

확장 0.3.8 · 작성일 2026년 11월 4일

온소리 자막 in YouTube는 YouTube 영상의 대사·음악·효과음을 접근성 자막으로 표시합니다.
기본으로 녹음한 소리와 화면 자막 이미지는 기기 안에서 분석합니다.
클라우드 대사 분석에 동의한 경우에만 영상 전체 분석의 소리를 온소리 서버와 외부 AI 업체 DeepInfra로 보냅니다.
광고 서비스로는 어떤 정보도 보내지 않습니다.

처리하는 정보와 목적

  • 현재 YouTube 영상의 ID·제목·재생 시각과 상태: 영상에 자막을 연결하고 녹음 시각을 맞춥니다.
    다른 사이트의 방문 기록을 수집하지 않습니다.
  • 사용 설정 후 현재 영상의 전체 오디오(20분·100MB 이하), 또는 사용자가 별도로 선택한 탭의 최대 60초 오디오: 대사·소리 분류 및 구간 평균 음량 분석에 사용합니다.
    마이크 입력을 요청하지 않습니다.
  • YouTube에서 제공되는 원래 자막: 같은 시각의 음성 인식 결과와 대조합니다.
    화면 자막 교정을 선택한 경우 영상 하단의 자막 이미지를 추가로 읽습니다.
  • 생성 자막, 설정, 진행 상태: 자막 표시와 재사용, 취소 및 오류 안내에 사용합니다.

클라우드 대사 분석(선택)

온소리 서버가 대사 분석을 제공하면 동의 화면에서 선택할 수 있고, ‘다른 방법’에서 언제든 끌 수 있습니다.
동의하면 영상 전체 분석 때 현재 영상의 소리(16kHz 모노 WAV, 20분 이하), 영상 ID, 제목을 온소리 서버(네이버 클라우드, 한국)로 보냅니다.
서버는 소리를 미국 업체 DeepInfra의 음성 인식 API로 보내 대사와 시각을 받아 옵니다.
음악·효과음 분석, 원래 자막 대조, 글자 크기 계산은 계속 이 기기에서 합니다.
서버는 받은 소리를 분석이 끝나면 지우고, 대사 결과는 24시간 뒤 지웁니다.
DeepInfra에서의 처리는 DeepInfra의 개인정보 처리 방침을 따릅니다.

처음 사용할 때 서버가 이 설치에만 쓰는 무작위 열쇠를 발급하며, 서버는 열쇠의 해시만 저장합니다.
열쇠는 이 설치의 작업 조회·취소와 하루 사용량(20분) 계산에 씁니다.
열쇠 발급 횟수를 제한하려고 접속 IP 주소를 일방향으로 변환한 값을 저장합니다.
서버 접근 기록에는 접속 IP 주소, 시각, 요청 경로, 응답 코드를 남기고 요청 본문과 인증 정보는 남기지 않습니다.
서버를 쓸 수 없거나 하루 사용량을 넘으면 그 영상의 대사는 이 기기에서 분석합니다.

저장 위치와 삭제

생성 자막과 설정은 이 Chrome 프로필의 확장 저장소에 보관합니다.
최근 최대 8개 영상의 자막을 용량 한도 안에서 유지하며 오래된 항목부터 교체합니다.
‘이 영상의 자막 지우기’로 해당 자막을 삭제할 수 있습니다.
원본 오디오와 화면 이미지는 분석 중 메모리에서 처리하며 디스크에 녹음 파일로 저장하지 않습니다.
완료·취소 후 참조를 해제하고 임시 데이터를 정리합니다.

모델 파일은 재다운로드를 줄이기 위해 브라우저 저장소에 캐시됩니다.
확장을 제거하면 확장 저장소도 제거됩니다.
직접 내려받은 JSON 파일은 사용자가 별도로 삭제해야 합니다.

인터넷 연결과 제3자 제공

전체 분석 시 현재 영상의 공개 페이지와 YouTube player API를 쿠키 없이 요청해 오디오 주소를 확인합니다.
익명 방문 문맥만 사용하며 로그인 쿠키나 계정 인증 정보를 읽지 않습니다.
확인한 직접 오디오 주소를 Google의 googlevideo.com 호스트에서 받으며, 제공되는 경우 youtube.com의 원래 자막을 읽습니다.
이 요청에는 영상 식별자와 IP 주소·HTTP 연결 정보가 Google에 전달됩니다.
오디오 요청에 쿠키를 넣지 않습니다.
클라우드 대사 분석에 동의하지 않으면 원본 오디오를 다른 서버에 업로드하지 않습니다.
클라우드 분석 제공 여부는 영상 정보 없이 온소리 서버에 상태만 물어 확인합니다.
처음 분석하거나 캐시된 모델이 없으면 Hugging Face 및 그 파일 전송 도메인, GitHub의 raw 파일 호스트에서 공개 AI 모델을 내려받습니다.
이 요청에는 모델 파일 주소와 연결에 필요한 IP 주소·HTTP 정보가 해당 제공자에게 전달됩니다.
영상 ID·제목, 녹음, 자막 이미지 및 분석 결과를 모델 다운로드 요청에 포함하지 않습니다.
자막 디자인에서 웹 글꼴을 고른 경우에만 Google Fonts(fonts.googleapis.com, fonts.gstatic.com)에서 그 글꼴의 스타일시트와 글꼴 파일을 내려받습니다.
이 요청에는 글꼴 이름과 IP 주소·HTTP 연결 정보가 Google에 전달되며, 스타일시트 요청에 YouTube 페이지 주소를 붙이지 않고 영상 ID·제목·자막 내용을 포함하지 않습니다.
기본값인 시스템 글꼴은 내려받지 않습니다.
YouTube 이용 과정 자체에는 Google의 정책이 적용됩니다.

온소리 자막 in YouTube는 사용자 데이터를 판매하거나 광고·추적에 사용하지 않습니다.
분석·사용 통계 전송 기능, 계정 가입 기능, 외부 분석 API 키 입력 기능은 없습니다.
문제 신고 링크를 직접 이용하면 GitHub에 작성한 내용이 전송되므로 공개 게시물에 개인 영상·녹음·민감한 정보를 올리지 마세요.

사용자의 선택

최초 사용 설정을 누르기 전에는 오디오를 받거나 녹음하지 않습니다.
탭 녹음은 ‘다른 방법’에서 별도로 선택할 때만 시작합니다.
자동 분석을 끄거나 작업 중 취소할 수 있습니다.
클라우드 대사 분석은 동의 화면에서 고르며 ‘다른 방법’에서 끌 수 있습니다.
화면 자막 이미지 분석은 선택 사항입니다.
음성·음악·효과음 표시와 글자 크기, X·Y 위치, 글꼴·테마·글자 색·외곽 효과·배경 색과 불투명도를 따로 조절할 수 있습니다.

권한의 사용

storage는 설정·자막 저장, activeTab과 tabCapture는 사용자가 허용한 현재 영상 탭의 소리 녹음, offscreen은 팝업을 닫아도 녹음과 기기 내 분석을 유지하는 데 사용합니다.
YouTube 접근 권한은 영상 옆 패널과 자막 표시, 현재 영상의 참조 자막 읽기에 사용합니다.
googlevideo.com 접근은 현재 영상의 전체 오디오 다운로드에 사용합니다.
모델 호스트 접근은 고정된 모델 파일 다운로드에만 사용합니다.
온소리 서버 연결에는 새 권한을 쓰지 않으며, 서버가 확장 프로그램의 요청만 허용합니다.

제한된 사용 및 문의

Google API로부터 받은 정보의 사용은 제한적 사용 요건을 포함한 Chrome 웹스토어 사용자 데이터 정책을 준수합니다.
The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
