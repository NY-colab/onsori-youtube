# 온소리 0.3.3 — 전체 오디오 분석 수정

YouTube 전체 오디오 주소를 찾지 못하거나 Chrome에서 HTTP 403으로 실패하던 경로를 수정했습니다. 영상 옆 패널 로딩을 보강하고 X·Y 자막 위치 설정을 실제 Chrome에서 검증했습니다.

## 다운로드 및 업데이트

아래 Assets의 **OnSori-Chrome-WebStore-0.3.3.zip**을 받으세요. 별도 EXE·Python·API 키가 필요하지 않습니다. Source code ZIP은 개발용입니다.

**기존 사용자:** ZIP 압축 해제 → 내용물 전부를 기존 확장 폴더에 덮어쓰기 → `chrome://extensions`의 온소리 카드 **⟳** → 버전 **0.3.3** 확인 → YouTube **F5**.

**⟳만 누르면 새 파일이 다운로드되지는 않습니다. 먼저 파일을 교체해야 합니다.** 확장을 삭제할 필요는 없습니다. [설치 위치 확인을 포함한 업데이트 안내](https://github.com/NY-colab/onsori-youtube/blob/main/docs/update.md)

**처음 설치:** ZIP 압축 해제 → `chrome://extensions` → 개발자 모드 → ‘압축해제된 확장 프로그램을 로드합니다’ → manifest.json이 있는 폴더 선택 → YouTube에서 ‘기기 내 분석 사용 설정’.

## 확인한 결과

- 자동 검사 110개 통과.
- 설치된 Chrome에서 6분 1초 영상 전체 오디오 분석 완료. 분석 중 영상은 일시정지 상태였으며 탭 녹음과 전체 재생을 사용하지 않았습니다.
- 실제 새 자막 119개 생성: 대사 82개·음악 25개·효과음 12개.
- X/Y 위치 이동, 새로고침 후 유지, 기본 위치 복원 확인.

## 알려진 제한

대사 인식 오류가 남아 있고, 음악의 세부 특징을 구별하지 못하면 일반적인 배경 음악 묘사가 표시됩니다. 전체 분석에는 화면 OCR이 적용되지 않습니다. CPU 분석이 느릴 수 있습니다. 위치 슬라이더의 키보드 방향키는 YouTube 탐색에도 영향을 줄 수 있어 마우스 조작을 권합니다. 전체 분석은 20분·100MB 이하의 지원 영상에 한하며 YouTube 변경·요청 제한에 따라 실패할 수 있습니다.

이 릴리스의 Latest 표시는 최신 GitHub 다운로드를 뜻하며 모든 인식 품질 문제가 해결됐다는 의미는 아닙니다. Chrome 웹스토어에는 아직 제출·공개되지 않았습니다.
