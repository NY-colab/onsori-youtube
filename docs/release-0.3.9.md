# 「온소리 자막 in YouTube」 0.3.9 · 가치봄식 소리 표기

## 소리 표기 규칙

효과음은 `♪ … ♪`, 배경음악은 `♬ … ♬`로 감싸 표시합니다.<br>사용자가 지정한 가치봄 기준(효과음 ♪…♪, 배경음 ♬…♬)을 따랐습니다.

| 종류 | 0.3.8까지 | 0.3.9 |
| --- | --- | --- |
| 효과음 | `[똑똑 문이나 단단한 표면을 두드리는 소리]` | `♪ 똑똑 문이나 단단한 표면을 두드리는 소리 ♪` |
| 배경음악 | `[♪ 피아노 연주]` | `♬ 피아노 연주 ♬` |
| ‘간결하게’ 정보 수준 | `[효과음]`, `[음악]` | `♪ 효과음 ♪`, `♬ 음악 ♬` |
| 대사 | 그대로 | 그대로 |

- 새로 분석한 자막은 저장되는 글자에 기호가 들어갑니다.
- 이전 버전에서 만든 자막, 가져온 JSON, `[ ]`로 감싼 자막도 화면과 SRT·VTT 내보내기에서 같은 규칙으로 바꿔 보여 줍니다.<br>기호를 두 번 붙이지 않습니다.
- 원래 자막·화면 자막과 대조할 때 ♪·♬가 들어간 줄은 대사 교정 근거로 쓰지 않습니다.
- 자막 디자인 미리보기와 사용 방법 화면의 예시를 새 표기로 바꿨습니다.

## 검증

- 확장 프로그램 Node 검사 151개를 2026-11-05에 실행해 모두 통과했습니다.
- 표기 함수 검사: 일반 문장, `[ ]` 자막, 이전 `♪ …` 음악 자막, 이미 바뀐 자막이 모두 같은 결과로 바뀌는지 확인했습니다.
- 생성 검사: 음악 상세 표시를 켰을 때와 껐을 때 모두 음악은 `♬ … ♬`, 효과음은 `♪ … ♪`로 만들어지는지 확인했습니다.
- 설치된 Chrome(0.3.9 새로고침 후)에서 0.3.8로 만든 평가 영상 자막 80개를 다시 열었습니다.<br>0분 50초 `♬ 배경 음악이 이어짐 ♬`, 1분 28초 `♪ 헉! 숨을 급히 들이마시는 소리 ♪`로 표시됐고, 자막 디자인 미리보기도 `♪ 문 닫히는 소리 ♪`, `♬ 배경 음악이 이어짐 ♬`로 나왔습니다.
