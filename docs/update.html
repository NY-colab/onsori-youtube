온소리 0.3.3 업데이트

새 파일을 넣고, ⟳ 한 번.

Chrome의 ⟳ 버튼은 설치된 파일을 다시 읽습니다.
새 ZIP의 내용물을 먼저 기존 확장 폴더에 덮어써 주세요.

  1. 새 ZIP 받기

    0.3.3 다운로드

    받은 ZIP을 임시 폴더에 압축 해제합니다.

  2. 기존 확장 폴더에 덮어쓰기

    분석 중이면 먼저 취소하거나 끝낸 뒤, 새 파일과 폴더 전부를 기존 설치 폴더에 복사하고 파일 덮어쓰기를 선택합니다.

    기존 manifest.json이 교체되어야 합니다.
    폴더를 한 단계 더 넣거나 기존 확장을 삭제하지 마세요.

  3. 온소리 카드 ⟳ → YouTube F5

    Chrome 주소창에 chrome://extensions를 입력하고, 온소리 카드 오른쪽 아래 켜기/끄기 스위치 옆 ⟳를 누릅니다. 상단 ‘업데이트’ 버튼과 다릅니다.

    버전이 0.3.3으로 바뀌면 YouTube 영상도 F5로 새로고침하세요.

기존 폴더가 어디인지 모르겠어요

확장 관리에서 개발자 모드 → 온소리 세부정보의 압축해제된 확장 경로를 확인하세요. 예전 Windows 설치형 기본값은 %LOCALAPPDATA%\OnSori\extension이지만 실제 등록 경로를 먼저 확인합니다.

새로고침했는데 버전이 그대로예요

다른 폴더에 복사했거나 폴더가 한 단계 더 들어갔을 수 있습니다. Chrome에 등록된 폴더의 manifest.json이 새 파일로 교체됐는지 확인하세요.
