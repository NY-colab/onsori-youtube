## 실제 오디오 결과와 발견한 오류

- **한국어 합성 음성 14.442초**: Whisper base CPU에서 5개 대사, 최대 4.74초·35자. 전사 1.639초(이 PC 단일 실행). `시간 분할을`이 `시간 분화를`로 인식된 오류를 보존했습니다. 합성 음성 시험을 사람 발화 정확도로 확대하지 않습니다.
- **JFK 11초**: 대사 3개, 최대 4.22초·37자. Whisper + AST + CoNeTTE 통합 실행 25.231초. 이 결과는 한국어 번역을 추가하기 전 실행입니다. 대사 단어 시각을 실제 Whisper 정렬 결과로 분할했습니다.
- **문 두드림 5초**: AST Knock 신뢰도 0.9593, 0.00–2.85초, 상대 음량 +8.54dB, 글자 배율 1.214. `[똑똑(크게 문이나 단단한 표면을 두드리는 소리)]` 생성. CoNeTTE의 문 두드림 영어 묘사와 OPUS-MT 한국어 번역까지 실제 실행했습니다.
- **번역 오류**: 위 묘사의 `tapping`이 `도청`으로 잘못 번역됐습니다. 영어 원문은 `metadata.captioning`에 남겼으며 편집기에서 상세 설명을 수정·되돌리는 과정을 검증했습니다. 자동 번역 결과를 사람이 다듬은 문장인 것처럼 제시하지 않습니다.
- **재채기 5초**: 정답 레이블은 sneezing이지만 AST가 Throat clearing 0.733으로 선택했습니다. Sneeze 점수는 0.052였습니다. 결과를 재채기로 강제 수정하지 않았습니다. 유사한 인간 소리의 구분은 추가 평가·모델 개선이 필요합니다.
- **trumpet / robin**: CoNeTTE는 각각 악기 연주와 새 지저귐을 묘사했습니다. 2개 구간 합계 11.297초(모델 로딩 포함). 개별 원문·출처는 [caption-engine.md](caption-engine.md)에 있습니다.
- 실제 YouTube의 AST `음악` 판정도 사람이 검토해야 합니다. 기존 자막의 비언어 표현 `(baaaaaaaaaaahhh!!)`은 기존 스크립트 출처를 유지했습니다. 소리 종류의 확정 정답으로 취급하지 않습니다.

## 구현됐으나 최종 사용자 환경 확인이 필요한 범위

**탭 녹음의 실제 권한 부여부터 오디오 수집까지는 미검수입니다.** 자동화에서 `chrome.action.openPopup()`로 팝업을 열면 Chrome이 사용자의 도구 모음 클릭으로 인정하지 않아 `activeTab` 오류가 났습니다. 실제 마이크나 다른 탭으로 대신 녹음하거나 권한을 우회하지 않았습니다. offscreen 녹음·60초 제한·정지/탐색 시 종료·업로드·타임라인 offset 연결 코드는 구현했고 worker 연결은 mock으로 검증했습니다. 실제 탭 오디오의 연속성 및 경계 오차는 다음 절차로 확인해야 합니다.

1. Chrome 도구 모음에서 온소리 아이콘을 직접 클릭합니다.
2. 광고 없는 YouTube 영상에서 `이 구간 1분 자막 만들기`를 누릅니다. 자동으로 1배속 재생을 시작합니다.
3. 영상 위에서 오디오 신호와 녹음 시간이 증가하는지 확인하고 `여기까지 녹음 · 분석`을 누릅니다. 완료 후 `자막으로 다시 보기`로 시작 시점에 돌아가 싱크를 확인합니다.
4. 다음 구간에서는 일시정지/탐색으로 자동 종료되는지, 원래 재생음이 유지되는지 확인합니다.

일반 재생·탐색·배속 동기화 계산은 자동 검사했고 실제 영상 오버레이도 확인했습니다. 모든 YouTube 화면 변형, 광고 종류, 라이브·DRM·연령 제한, 운영체제별 사용자 Chrome, 일반 영상 PiP에서의 표시까지 보증하지 않습니다. 일반 PiP는 페이지 DOM 오버레이를 담지 않습니다.

## 2026-10-24 사용 흐름 및 녹음 안정성 수정

- **사용 흐름**: 1분 구간 만들기를 주 버튼으로 배치하고 분석 옵션·자막 모양·파일 관리를 접었습니다. 일시정지/2배속 상태에서 시작해도 재생/1배속으로 맞춥니다. 팝업을 닫은 뒤에도 영상 위 안내에서 진행 상태·오디오 입력·중단·취소·완료 후 다시 보기를 사용할 수 있습니다. 서버 미실행 시 실행할 파일과 재확인 동작을 안내합니다.
- **취소·재시작 오류**: 녹음 세션마다 captureId, stream, recorder, chunks, 타이머, 업로드 취소 컨트롤러를 분리했습니다. 이전 녹음의 늦은 종료·오류·업로드가 새 녹음을 덮어쓰거나 종료하지 못하게 했습니다. 취소 뒤 뒤늦게 생성된 서버 작업도 취소합니다.
- **시간축**: 영상 시각 스냅샷과 실제 녹음 시작 사이 지연을 1초 이내에서 보정하고, 더 오래 지연되면 재시도 오류를 표시합니다. 버퍼링·페이지 새로고침 시 녹음을 마쳐 재생 시각과 녹음 시간의 누적 차이를 방지합니다. 이것만으로 실제 Chrome의 캡처 지연을 실측했다고 주장하지 않습니다.
- **자동 회귀 검사**: Node **32개 통과**(기존 core/review/worker 검사 + offscreen 10개 + worker 추가 6개). 취소 중 스트림 준비, 구세션 콜백, 녹음 오류 후 업로드 방지, 늦은 작업 취소, 신호 전달, 준비 시각 보정, 재생 상태 자동 준비, 서버 미실행/광고 선제 차단, 출처·세션 검증, 다시 보기 대상 확인을 포함합니다.
- **격리된 Chromium 화면 검사**: 388×600 팝업에서 주 버튼과 녹음 중단 버튼이 스크롤 없이 노출됨(중단 버튼 하단 496.8px). 서버 미실행 안내, 신호 없음 안내, 중단, 완료 후 다시 보기, 영상 위 안내 접기/펼치기, 390px 화면, 다른 영상으로 이동 시 이전 안내 숨김, 버퍼링 이벤트 시 녹음 중단 요청 확인. 합성 WAV를 사용한 실제 HTMLMediaElement에서 일시정지/2배속 → 재생/1배속, 다시 보기 요청 1.000초 → 확인 1.004초. pageerror 0.

## 2026-10-25 YouTube 오른쪽 패널

- **배치와 조작**: YouTube `#secondary-inner` 추천 영상 영역 위에 자체 확장 iframe을 삽입했습니다. 기존 YouTube/다른 확장 노드는 보존합니다. 패널에서 1분 분석, 상태·오디오 신호, 중단·취소·다시 보기, 자막 설정과 파일 관리를 사용합니다. 접기·펼치기, 좁은 화면/영화관 모드의 영상 아래 배치, 페이지 전환 및 DOM 교체 후 재부착을 지원합니다. 영상 자막 오버레이는 유지합니다.
- **발견·수정**: Chrome은 확장 iframe의 `document.referrer`를 비워 전달해 URL 생성 예외가 났습니다. 허용된 YouTube origin만 명시적으로 전달하고 메시지 출처·발신 창을 검증하도록 수정했습니다. 토글의 장식 span이 입력 클릭을 가리는 문제도 수정했습니다. 영상 제목이 늦게 갱신되는 경우 패널도 따라 갱신합니다.
- **탭 연결**: embedded panel은 현재 포커스 탭 대신 `MessageSender.tab.id`로 탭을 다시 조회합니다. 상태·URL 분석·녹음·JSON 가져오기/삭제·다시 보기가 해당 탭에 연결됩니다. 다른 탭의 진행 작업에는 중단/취소 버튼을 표시하지 않습니다.
- **Node 회귀 검사**: **36개 통과**. 기존 32개와 패널의 탭 연결·분석/녹음 대상·자막 가져오기/삭제·닫힌 탭 처리 4개를 포함합니다.
- **실제 확장 로드 UI 검사**: 격리 Chromium 프로필에서 manifest/worker/content script/확장 iframe을 실제 로드했습니다.
