# 「온소리 자막 in YouTube」 0.4.4 · 새 버전 빨리 받기

## 바뀐 동작

- 웹스토어에서 설치한 확장 프로그램은 Chrome이 몇 시간마다 새 버전을 확인합니다.<br>새 버전을 올려도 이용자에게 닿기까지 시간이 걸렸습니다.
- 0.4.4부터 브라우저를 켤 때와 YouTube 영상을 열 때 웹스토어에 새 버전을 바로 확인합니다(`chrome.runtime.requestUpdateCheck`).<br>영상을 열 때의 확인은 한 시간에 한 번까지만 합니다.
- 새 버전은 Chrome이 확장 프로그램의 백그라운드 작업이 쉬는 순간에 설치합니다.<br>진행 중인 분석은 끊기지 않습니다.
- ZIP으로 설치한 확장(개발자 모드)은 받을 곳이 없어 이 기능과 관계가 없습니다.
- 권한과 외부로 보내는 데이터는 0.4.3과 같습니다.

## 확인 결과

- 확장 검사 196개를 2026-11-27에 실행해 모두 통과했습니다.<br>영상을 두 번 열면 확인 요청이 한 번만 나가고, 한 시간이 지나면 다시 나가는 검사를 더했습니다.
