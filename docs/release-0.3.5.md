# 온소리 0.3.5 — 자막 디자인: 글꼴·테마·배경

패널의 **자막 디자인 · 글꼴 · 테마** 영역에서 자막 모양을 바꿀 수 있습니다. 바꾸지 않은 사용자에게는 0.3.4와 같은 모양(온소리 기본 테마, 시스템 글꼴)이 그대로 보입니다. 분석 결과와 자막 크기 규칙(단락 안 단일 배율)은 바뀌지 않았습니다.

## 추가된 기능

- **테마 6종**: 온소리 기본, 방송 자막(글줄 띠), 고대비(검정 바탕에 노랑), 외곽선(배경 없음), 영화관(배경 없음·그림자), 밝은 상자(흰 바탕에 검정 글자). 테마를 누르면 굵기·색·외곽 효과·배경 값이 한 번에 바뀌고, 글꼴은 사용자가 고른 것을 유지합니다. 값을 하나라도 바꾸면 "직접 바꾼 디자인"으로 표시됩니다.
- **글꼴**: Google Fonts 공식 메타데이터에서 `korean` 서브셋을 지원하는 38종을 고딕·명조·손글씨·장식으로 나눠 제공합니다. 다른 Google Fonts 이름을 직접 입력할 수도 있습니다. 시스템 기본 글꼴은 아무것도 내려받지 않습니다.
- **굵기**: 보통, 중간, 굵게, 아주 굵게. 글꼴에 없는 굵기는 가장 가까운 실제 굵기로 표시하고, 그 사실을 패널에 안내합니다. 가짜 굵게(합성)는 쓰지 않습니다.
- **글자**: 글자 색, 외곽 효과(없음·그림자·외곽선·돋움·눌림), 외곽 색.
- **배경**: 배경 색, 불투명도(0–100%, 5% 단위), 모서리 둥글기(0–24px), 형태(줄마다 상자·글줄 띠·하나로 묶기).
- **유형 구분**: 색 막대와 글자색, 글자색만, 구분 없음. 대사·효과음·음악 구분 색은 글자 색이 밝은지 어두운지에 따라 바뀌어, 밝은 상자 테마에서도 읽힙니다.
- **미리보기**: 패널에서 실제 자막과 같은 CSS로 대사·효과음·음악 세 줄을 보여 줍니다. 어두운 장면과 밝은 장면을 전환해 볼 수 있습니다.

## 글꼴 내려받기와 개인정보

- 글꼴을 고른 페이지(YouTube 또는 도구 모음 팝업)에 `fonts.googleapis.com/css2` 스타일시트 하나를 추가합니다. YouTube의 CSP는 `script-src`만 제한하므로 이 방식이 허용됩니다. 스크립트는 받지 않습니다.
- 스타일시트 요청은 `referrerpolicy="no-referrer"`로 보내 YouTube 페이지 주소를 전달하지 않습니다. 글꼴 파일은 고른 굵기 하나만 요청하고, 한글 글꼴은 Google이 나눈 글자 묶음 가운데 화면에 나온 글자의 묶음만 받습니다.
- 새 권한은 추가하지 않았습니다(`permissions`, `host_permissions` 변화 없음). 개인정보 안내(`privacy.html`)와 도움말(`help.html`)에 Google Fonts 요청을 적었습니다.
- 목록을 키보드로 훑을 때 지나가는 글꼴은 내려받지 않습니다. 0.45초 동안 그대로 두면 그 글꼴을 저장하고 불러옵니다.

## 확인한 결과

- 자동 검사: `node --test extension/*.test.mjs web/review.test.mjs` **118개 통과**. 새 검사는 글꼴 이름 주입 차단, 기존 설정이 온소리 기본 테마로 유지되는지, 굵기 선택, 테마 값, 글꼴 불러오기 실패 처리, 패널 저장 흐름입니다.
- 실제 YouTube 시청 페이지(`-wbEQJ_ZXyk`)에서 이 확장 폴더를 불러온 별도 Chromium(Playwright, 새 프로필, 분석 동의 없음)으로 확인했습니다. 시험용 자막 3줄을 확장 저장소에 넣고, 패널은 실제 클릭과 키 입력으로만 조작했습니다.
  - 테마 6종과 글꼴 Noto Sans KR, Black Han Sans, Nanum Pen Script, Gowun Batang, Roboto Slab(직접 입력), IBM Plex Sans KR이 영상 위 자막과 패널 미리보기에 적용되고, `document.fonts`에서 해당 글꼴이 실제로 불러와진 것을 확인했습니다.
  - 없는 이름(`Nonexistent Fontxyz`)을 입력하면 시스템 글꼴로 표시되고, 패널에 실패 안내가 나왔습니다.
  - 하나로 묶기·불투명도 60%·모서리 14px 설정이 새로고침 뒤에도 유지되었고, 디자인 초기화로 온소리 기본 테마로 돌아갔습니다. 페이지 오류는 0건이었습니다.
  - 확장이 보낸 스타일시트 요청에는 Referer가 없었습니다. 글꼴 파일 요청의 Referer는 `https://fonts.googleapis.com/`이거나 비어 있었습니다. `youtube.com` Referer가 붙은 Google Fonts 요청은 YouTube가 직접 요청한 Roboto 스타일시트와 아이콘 SVG뿐이었습니다.
  - 새 컨트롤(굵기·배경 형태 선택 상자, 불투명도 슬라이더, 색 선택, 테마 버튼, 장면 전환 버튼)에 포커스를 두고 `k`·방향키·Space·Enter를 눌러도 영상 시각·재생 상태·음량이 바뀌지 않았습니다.
  - 도구 모음 팝업(372px)에서도 디자인 영역이 가로 넘침이나 콘솔 오류 없이 표시되었습니다.
- 사용자의 설치된 Chrome(⟳ 후, 2026-10-31): 패널에 디자인 영역과 글꼴 목록(시스템 기본·38종·직접 입력)이 표시되었습니다. 기존 설정은 온소리 기본 테마로 유지되었고, 저장된 자막 119개가 그대로 연결되었습니다. 고대비 테마를 실제 클릭으로 고르자 영상 위 자막이 검정 바탕·노란 글자·굵기 800으로 바뀌었습니다. 디자인 초기화로 원래 모양으로 되돌렸고, 그동안 일시정지한 영상의 재생 위치는 19초에서 움직이지 않았습니다.
- 시험 기록: `work/onsori/claude-design-qa/run3/result.json`과 화면 캡처.

## 함께 고친 점

- 일시정지 상태에서 페이지를 스크롤하면 자막 위치가 최대 1초 늦게 맞춰지던 것을, 스크롤할 때 바로 다시 맞추도록 했습니다.
- 공유 모듈 `caption-style.js`를 `web/`에도 같은 내용으로 두었습니다(`core.js`와 같은 방식이며 검사로 확인). 클라우드 준비 묶음 목록에도 넣었습니다.

## 알려진 제한

- 한글 글리프가 없는 Google Fonts 글꼴은 영문·숫자에만 적용되고, 한글은 시스템 글꼴로 보입니다.
- 글꼴 서버에 연결되지 않으면 시스템 글꼴로 표시합니다. 오프라인 사용을 위해 글꼴을 확장에 넣지는 않았습니다(패키지 크기 문제).
- Chrome 웹스토어 제출, GitHub 릴리스, 커밋은 하지 않았습니다.
