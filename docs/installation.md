# Windows 간편 설치

`OnSori-Setup.exe`를 실행하고 **온소리 설치**를 누릅니다. Windows 10/11 x64용이며 온소리는 사용자 폴더에 설치됩니다. Microsoft Visual C++ 실행 구성요소가 없으면 공식 설치 파일을 내려받아 서명을 확인한 뒤 실행하므로, Windows 설치 승인이나 재시작이 필요할 수 있습니다. [Microsoft 공식 안내](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist/) 설치 위치는 `%LOCALAPPDATA%\OnSori`입니다. 설치 중 다운로드와 모델 검사가 끝나면 Chrome 등록 안내가 표시됩니다.

## 처음 한 번만 직접 할 일

설치 완료 화면의 **① 확장 폴더 복사 + Chrome 설정 열기**를 누릅니다.

1. Chrome 오른쪽 위 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. 폴더 선택 창 위 **Alt+D → Ctrl+V → Enter**를 누르고 **폴더 선택**을 누릅니다.

Chrome에 등록한 후 YouTube 영상을 열거나 새로고침합니다. 영상 옆 온소리 패널이 자동으로 나타납니다. 탭 녹음 권한 안내가 나오면 Chrome 퍼즐 아이콘에서 **온소리 자막 in YouTube**를 한 번 누릅니다. 마이크 권한이나 모든 웹사이트 권한을 줄 필요는 없습니다.

Chrome 웹 스토어 등록 전에는 이 과정을 생략할 수 없습니다. 조직이 개발자 모드나 외부 확장 설치를 차단한 PC에서는 관리자 정책을 따라야 합니다.

## 다음 사용과 종료

- 바탕화면 **OnSori**를 실행하면 로컬 서버를 준비하고 Chrome YouTube를 엽니다.
- 설치 때 **Windows 로그인 시 분석 서버 자동 준비**를 선택했다면 로그인 시 서버가 백그라운드에서 시작됩니다. 기본은 선택하지 않은 상태입니다.
- 서버는 켜 둔 동안 다음 영상에서도 사용할 수 있습니다. 종료하려면 설치 폴더의 `Stop-OnSori.cmd`를 실행합니다.
- 설치 창을 닫은 뒤 확장 등록 안내가 다시 필요하면 시작 메뉴의 **OnSori 설치 안내**를 엽니다.
- 분석은 녹음 후 처리 방식이며, 모델을 준비했어도 영상마다 분석 시간이 필요합니다.

## 실패하거나 업데이트할 때

- **다운로드 실패:** 네트워크와 디스크 공간을 확인한 뒤 **다시 시도**를 누릅니다. 모델과 다운로드 캐시는 재사용합니다. Python·Node.js를 수동 설치할 필요는 없습니다.
- **실행 중 안내:** 같은 설치 폴더의 `Stop-OnSori.cmd`로 서버를 종료하고 설치를 다시 시도합니다. 진행 중인 분석은 먼저 완료하세요.
- **다른 서버가 실행 중:** 이전 ZIP 폴더 등에서 실행한 온소리는 그 폴더의 `Stop-OnSori.cmd`로 종료합니다. 새 설치가 다른 서버를 임의 종료하지 않습니다.
- **설치 후 확장이 안 보임:** `chrome://extensions`에서 온소리를 확인합니다. 새 버전 설치 후에는 온소리 카드의 **새로고침(⟳)**을 누르고 YouTube 페이지도 새로고침합니다. 이전 ZIP의 확장을 등록해 뒀다면 새 설치 폴더의 `extension`으로 다시 등록해야 합니다.
- **설치 로그:** `%LOCALAPPDATA%\OnSori\runtime\setup.log`. 서버 오류는 같은 폴더의 `server-error.log`입니다.
- **Windows 경고:** 실행 파일에는 아직 코드 서명이 없습니다. 보안 프로그램을 끄거나 회사·학교의 제한을 우회하지 마세요.

## 제거

진행 중인 분석이 끝나면 `Stop-OnSori.cmd`로 서버를 종료합니다. Chrome 확장 관리에서 온소리를 제거하고, 필요한 자막 JSON을 따로 보관한 뒤 `%LOCALAPPDATA%\OnSori` 폴더와 바탕화면·시작 메뉴의 OnSori 바로가기를 삭제합니다. 로그인 자동 시작을 선택했다면 Windows 시작프로그램 폴더의 `OnSori.lnk`도 삭제합니다. 이 폴더를 삭제하면 보관된 녹음과 모델도 함께 지워집니다.

## 배포 구성

- 공개 소스 ZIP을 EXE 안에 포함하며, 소스 해시를 모두 검사한 뒤 설치합니다.
- uv 0.13.5와 Node.js 24.22.1 Windows x64 ZIP은 공식 배포처에서 받고 SHA-256을 확인합니다.
- Python 3.10.20, 의존성, 모델은 앱 전용 폴더에 설치합니다. 시스템 PATH 및 Python 레지스트리 등록을 변경하지 않습니다.
- Whisper base, AST, 한국어 PaddleOCR의 실제 모델 로딩과 API 상태를 검사해야 설치 완료가 표시됩니다. CoNeTTE는 선택 설치입니다.
- 바탕화면·시작 메뉴 바로가기를 만듭니다. 로그인 자동 시작은 사용자가 체크한 경우에만 추가합니다.
- Windows 앱 목록에 등록하는 MSI 방식은 아닙니다. 위 제거 절차를 사용합니다.

개발자는 `python scripts/build_installer.py`로 소스 ZIP과 설치 파일을 만들 수 있습니다(Windows .NET Framework C# 컴파일러 필요). `OnSori-Setup.exe --install-test "빈 폴더 경로"`는 바로가기·브라우저·자동 시작을 바꾸지 않는 설치 검증 경로입니다. 기본 다운로드·모델 검사를 그대로 수행합니다.
