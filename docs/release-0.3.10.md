# 「온소리 자막 in YouTube」 0.3.10 · 확장 프로그램 재시작 후 연결 안내

## 고친 문제

0.3.4 내부 테스트에서 분석 중 확장 프로그램이 다시 불러와지면 `Extension context invalidated` 오류(content.js 534번째 줄 safeSend)가 나고, YouTube 탭을 새로고침해야 다시 연결되는 문제를 보고받았습니다.<br>확장 프로그램이 업데이트되거나 `chrome://extensions`에서 새로고침되면, 이미 열려 있던 YouTube 탭의 화면 스크립트는 Chrome과의 연결을 잃은 채 계속 실행됩니다.<br>이때 `chrome.runtime.sendMessage`는 오류를 바로 던지는데, 기존 코드는 비동기 오류만 처리해서 이 오류를 잡지 못했습니다.<br>1초마다 실행되는 화면 점검도 같은 오류를 반복했고, 분석 중이었다면 상태 창이 ‘소리 분석 중’에서 바뀌지 않았습니다.

## 바뀐 동작

- 연결이 끊긴 것을 처음 감지하면 1초 점검과 화면 변화 감시를 멈춥니다.<br>메시지를 보내는 모든 경로가 `extension/connection.js`의 확인을 거쳐, 오류 대신 빈 응답을 받습니다.
- 영상 위 상태 창에 ‘온소리 · 연결이 끊어졌습니다’와 **이 탭 새로고침** 버튼을 표시합니다.<br>분석 중이었다면 진행 중이던 분석이 멈췄으니 새로고침한 뒤 다시 시작하라고 안내합니다.
- 옆 패널은 더 이상 동작하지 않는 설정·분석 버튼 대신 같은 안내와 **이 탭 새로고침** 버튼을 보여 줍니다.<br>버튼은 사용자가 직접 누른 입력만 받습니다.
- 이미 불러온 자막은 새로고침 전까지 계속 표시합니다.<br>같은 탭에서 다른 영상으로 이동하면 이전 영상의 자막은 숨깁니다.
- 툴바 창에서 같은 상황이 생기면 영어 원문 대신 “확장 프로그램이 다시 불러와져 연결이 끊어졌습니다. 이 탭을 새로고침해 주세요.”를 표시합니다.
- 탭을 새로고침한 뒤에는 기존 동작대로, 멈춘 작업을 다시 실행하지 않고 ‘확인이 필요합니다’ 상태로 안내합니다.

## 검증

- Node 검사 157개(`extension`·`web`·`eval`·`integrations/client`)를 2026-11-05에 실행해 모두 통과했습니다.<br>새 검사 6개는 오류를 바로 던지는 경우, 확장 ID가 사라진 경우, 일반 전달 실패와의 구분, 안내 문구, 패널 교체와 직접 누른 입력만 받는 새로고침 버튼을 확인합니다.
- 실제 YouTube 영상(평가 영상 `-wbEQJ_ZXyk`)을 Playwright Chromium에서 열고, 자막을 보던 중과 분석 중 두 경우에 확장 프로그램을 다시 불러왔습니다(`work/onsori/claude-design-qa/reload-qa.mjs`).

| | 페이지 오류 | 다시 불러온 뒤 화면 |
| --- | --- | --- |
| 0.3.9 | `Extension context invalidated` 2건(두 경우 모두) | 분석 중 상태 창이 ‘소리 분석 중’에 멈춤 |
| 0.3.10 | 0건 | 상태 창·패널에 연결 끊김 안내와 새로고침 버튼, 기존 자막 유지 |

(*Playwright Chromium에서는 `chrome.runtime.reload()`가 압축해제 확장을 내리기만 하고 다시 올리지 않습니다.)<br>탭 새로고침 후 다시 연결되는 단계는 기존 작업 복구 검사(‘orphaned operation becomes actionable error’)로 확인했습니다.
