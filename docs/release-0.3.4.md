# 온소리 0.3.4 — 패널 키보드 입력 수정, 음악 구간 대사 환각 감소

온소리 패널의 X·Y 위치 슬라이더, 기본 크기 입력칸, 체크박스, 버튼에서 누른 키가 YouTube 재생 단축키로도 전달되던 문제를 고쳤습니다. 음악만 흐르는 구간에 생기던 짧은 가짜 대사(`그러니까`, `뭐야` 등)를 소리 근거로 걸러 냅니다. 위치 저장, 완료 후 표시, 단락별 고정 크기는 0.3.3과 같습니다.

## 대사 필터

- 정규화 후 8자 이하인 짧은 대사이고, 겹치는 AST 2초 창 어디에서도 사람 말소리(Speech) 점수가 0.2에 닿지 않으면 표시하지 않습니다. 걸러 낸 문장과 점수는 결과 JSON `metadata.speech_filter`에 남습니다. 긴 문장은 이 규칙으로 지우지 않습니다.
- 대사 앞에 붙던 Whisper의 화자 전환 기호 `- `를 표시하지 않습니다.
- 기준 영상 평가([eval-20261030.md](eval-20261030.md)): 화면 자막 초안 대비 CER 0.455→0.427, 기준 없는 대사 16→5, 화면 자막과 겹치는 대사 손실 0. 남은 5개는 기준을 영상 하나에 맞추지 않아 그대로 둡니다. 특정 문장을 맞추는 규칙은 없습니다.
- `이것은 옷이오` 같은 음절 오인식은 그대로입니다. 전체 분석 모드가 화면 자막 근거를 쓰지 못하기 때문이며 다음 개선 대상입니다.

## 바뀐 점

- 온소리 패널과 영상 위 진행 안내는 YouTube 페이지 안의 Shadow DOM이라, YouTube는 키 입력이 입력칸이 아닌 온소리 요소에서 왔다고 판단했습니다. 이제 **포커스된 온소리 컨트롤이 직접 쓰는 키만** 온소리 안에서 멈춥니다.
  - 슬라이더: 방향키, Home/End, PageUp/PageDown
  - 숫자·글자 입력칸, 선택 상자: 모든 키
  - 체크박스·버튼·접기 제목: Space, Enter
- 그 밖의 키(예: 슬라이더에 포커스가 있을 때 `k`)와 **온소리 밖에서 누른 모든 키는 그대로 YouTube 단축키로 동작**합니다.
- 위치 저장·새로고침 후 유지·초기화(50/88)는 그대로입니다.

## 확인한 결과

- 자동 검사 116개 통과(기존 110, 키 입력 1, 평가 도구 5). 대사 필터 검사는 기존 항목을 새 기준으로 갱신했습니다.
- 사용자의 설치된 Chrome에서 실제 영상 위치 슬라이더 ←·→가 위치만 바꾸고 영상 시각(45초)은 그대로임을 확인했습니다.
- 실제 YouTube 시청 페이지(`-wbEQJ_ZXyk`)에 이 확장 폴더를 로드한 별도 Chromium(Playwright, 새 프로필)에서 수정 전 0.3.3과 같은 스크립트로 비교:

| 조작 | 0.3.3 | 0.3.4 |
| --- | --- | --- |
| X 슬라이더 → 3회 | 위치 50→53, **영상 30→45초 이동** | 위치 50→53, 영상 30초 유지 |
| 기본 크기 칸에 `16` 입력 | **영상 216.67초(60%)로 이동** | 값 16, 영상 유지 |
| 체크박스 Space | 체크 그대로, **영상 재생 시작** | 체크 해제, 영상 정지 유지 |
| 진행 안내 접기 버튼 Space | 접히지 않고 **영상 재생 시작** | 접힘, 영상 정지 유지 |
| 온소리 밖 플레이어에서 → | 30→35초 | 30→35초(유지) |

- 키로 바꾼 위치 0/88이 새로고침 뒤 유지되고 초기화로 50/88이 됨을 확인했습니다.
- 위 브라우저 확인은 사용자의 설치된 Chrome 프로필이 아닌 별도 Chromium입니다. 설치된 Chrome은 확장 다시 로드 후 따로 확인합니다.

## 알려진 제한

0.3.3의 제한(대사 오인식, 일반적인 음악 묘사, 전체 분석의 화면 OCR 미적용, CPU 분석 지연, 20분·100MB 지원 범위)은 그대로입니다. Chrome 웹스토어에는 제출·공개되지 않았고 GitHub 릴리스도 게시하지 않았습니다. 사용자용 업데이트 안내(`update.md`)의 다운로드 링크는 실제 릴리스를 게시할 때 0.3.4로 바꿉니다.
