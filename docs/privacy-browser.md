# 「온소리 자막 in YouTube」 개인정보 안내 · 0.3.8 이상

작성일: 2026-11-05. 확장에 포함된 `privacy.html`과 같은 내용을 요약합니다.

- 목적: 현재 YouTube 영상의 대사·음악·효과음과 구간 평균 음량을 분석해 접근성 자막으로 표시합니다.
- 입력: 현재 영상 ID·제목·재생 상태, 제공되는 전체 오디오(20분·100MB 이하), 원래 자막입니다. 탭 녹음은 직접 선택했을 때만 최대 60초 수집하며, 화면 자막 이미지는 해당 녹음 옵션을 켠 경우에만 읽습니다. 마이크는 요청하지 않습니다.
- 기본 처리: 오디오와 화면 자막 이미지는 사용자의 Chrome 안에서 분석합니다. GPU를 쓸 수 있으면 GPU로, 아니면 CPU로 실행합니다.
- 클라우드 대사 분석(선택): 온소리 서버가 대사 분석을 제공할 때 동의 화면에서 선택하며, ‘다른 방법’에서 언제든 끌 수 있습니다. 동의하면 영상 전체 분석 때 현재 영상의 소리(16kHz 모노 WAV, 20분 이하), 영상 ID, 제목을 온소리 서버(네이버 클라우드, 한국)로 보냅니다. 서버는 소리를 미국 업체 DeepInfra의 음성 인식 API로 보내 대사와 시각을 받아 옵니다. 음악·효과음 분석, 원래 자막 대조, 글자 크기 계산은 계속 기기에서 합니다. 서버는 받은 소리를 분석이 끝나면 지우고 대사 결과는 24시간 뒤 지웁니다. DeepInfra에서의 처리는 DeepInfra의 개인정보 처리 방침을 따릅니다.
- 설치별 열쇠: 클라우드를 처음 쓸 때 서버가 이 설치에만 쓰는 무작위 열쇠를 발급하고, 서버는 열쇠의 해시만 저장합니다. 열쇠는 작업 조회·취소와 하루 사용량(20분) 계산에 씁니다. 발급 횟수 제한을 위해 접속 IP 주소를 일방향으로 변환한 값을 저장합니다. 서버 접근 기록에는 접속 IP 주소, 시각, 요청 경로, 응답 코드를 남기고 요청 본문과 인증 정보는 남기지 않습니다. 동의하지 않으면 원본 오디오를 다른 서버에 업로드하지 않으며, 클라우드 제공 여부는 영상 정보 없이 상태만 물어 확인합니다.
- 통신: 전체 오디오를 Google의 googlevideo.com, 원래 자막을 youtube.com에서 받습니다. 영상 식별자, IP 주소와 HTTP 연결 정보는 Google에 전달됩니다. 오디오 요청에는 쿠키를 보내지 않습니다.
- 모델: 처음 사용하거나 캐시가 없을 때 Hugging Face 및 파일 전송 도메인과 GitHub raw 호스트에서 공개 모델 데이터를 받습니다. 모델 요청에는 연결 정보가 전달되지만 영상 ID·오디오·자막·결과는 포함하지 않습니다. 실행 JS/WASM은 확장에 들어 있습니다.
- 글꼴: 자막 디자인에서 웹 글꼴을 고른 경우에만 Google Fonts에서 그 글꼴을 받습니다. 요청에는 글꼴 이름과 연결 정보가 전달되며 영상 ID·제목·자막 내용은 포함하지 않습니다.
- 저장: 설정·자막·진행 상태·동의 선택·설치별 열쇠는 Chrome 확장 저장소에 저장합니다. 최근 최대 8개 영상의 결과를 용량 한도 안에서 보관합니다. 원본 오디오·화면 이미지는 기기에서 메모리로만 처리하고 작업 후 해제합니다. 모델은 브라우저에 캐시합니다.
- 선택: 첫 사용 설정 전에는 분석·녹음하지 않습니다. 자동 분석을 끄거나 진행 중 취소할 수 있습니다. 전체 분석 실패 시 자동 녹음하지 않습니다. 표시 종류·크기·X/Y 위치·디자인을 조절할 수 있습니다.
- 권한: storage는 저장, activeTab/tabCapture는 직접 선택한 탭 녹음, offscreen은 지속적인 분석과 동의한 경우의 클라우드 전송, YouTube는 패널·자막·현재 영상 정보, googlevideo.com은 전체 오디오, 모델 호스트는 모델 다운로드에 사용합니다. 온소리 서버 연결에는 새 권한을 쓰지 않습니다.
