# 온소리 브라우저 확장 개인정보 안내 · 0.3.0

작성일: 2026-10-28. 확장에 포함된 `privacy.html`과 함께 제공됩니다.

- 목적: 현재 YouTube 영상의 대사·음악·효과음 및 구간 평균 음량을 기기 안에서 분석하여 자막을 표시합니다.
- 입력: 현재 영상 ID·제목·재생 상태, 제공되는 전체 오디오(20분·100MB 이하), 원래 자막. 탭 녹음은 직접 선택했을 때만 최대 60초 수집하며, 화면 자막 이미지는 해당 녹음 옵션을 켠 경우에만 읽습니다. 마이크는 요청하지 않습니다.
- 통신: 전체 오디오를 Google의 googlevideo.com, 원래 자막을 youtube.com에서 받습니다. 영상 식별자, IP 주소와 HTTP 연결 정보는 Google에 전달됩니다. 오디오 요청에는 쿠키를 보내지 않습니다. 분석 입력을 운영자 서버나 외부 AI API에 업로드하지 않습니다.
- 모델: 처음 사용하거나 캐시가 없을 때 Hugging Face 및 파일 전송 도메인과 GitHub raw 호스트에서 공개 모델 데이터를 받습니다. 모델 요청에는 연결 정보가 전달되지만 영상 ID·오디오·자막·결과는 포함하지 않습니다. 실행 JS/WASM은 확장에 포함됩니다.
- 저장: 설정·자막·진행 상태는 Chrome 확장 저장소에 저장합니다. 최근 최대 8개 영상의 결과를 용량 한도 안에서 보관합니다. 원본 오디오·화면 이미지는 메모리에서만 처리하고 작업 후 해제합니다. 모델은 브라우저에 캐시합니다. ‘이 영상 자막 지우기’로 결과를 지울 수 있으며 직접 내보낸 JSON은 별도로 삭제해야 합니다.
- 선택: 첫 사용 설정 전에는 분석·녹음하지 않습니다. 자동 분석을 끄거나 진행 중 취소할 수 있습니다. 전체 분석 실패 시 자동 녹음하지 않습니다. 표시 종류·크기·X/Y 위치를 조절할 수 있습니다.
- 권한: storage는 저장, activeTab/tabCapture는 직접 선택한 탭 녹음, offscreen은 지속적인 기기 내 분석, YouTube는 패널·자막·현재 영상 정보, googlevideo.com은 전체 오디오, 모델 호스트는 모델 다운로드에 사용합니다.
- 광고·추적·통계 전송·개인정보 판매가 없습니다. 직접 GitHub Issues를 이용하면 게시한 내용이 GitHub에 전달됩니다.
