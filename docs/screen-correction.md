# 화면 자막 기반 대사 교정 검증 · 2026-10-25

대상: https://www.youtube.com/watch?v=-wbEQJ_ZXyk (조선에 롱패딩을 팔았다)

## 구현

- 제작자 제공 자막과 녹음 중 관찰한 YouTube CC를 우선 대조한다.
- 참조로 교정되지 않은 한국어 Whisper 대사는 PaddleOCR의 한국어 PP-OCRv5로 화면 자막을 읽어 대조한다.
- 탭 녹음 중 동영상 하단 40%의 픽셀만 최대 241장 수집한다. 주소창·다른 창·댓글·온소리 오버레이는 포함하지 않는다. CORS/DRM 제한을 우회하지 않는다.
- 이미지가 없으면 접근 가능한 공개 원본 영상에서 같은 구간을 읽는다. 로그인 쿠키나 외부 AI API는 사용하지 않는다.
- 신뢰도 0.94 이상으로 반복 관찰한 문구를 영상 ID·시각·문자열·한글 자모로 비교한다. 인식이 나뉜 인접 대사는 하나의 화면 문장으로 합칠 수 있다. 무관한 문구, 일회 관찰, 일부만 보이는 문장으로 원문 전체를 덮어쓰지 않는다.
- 교정 전 텍스트·단어·출처는 JSON에 남긴다. 문장을 합치면 평균 RMS로 크기를 다시 계산하며 표시 중 크기는 고정된다.
- 교정 단계를 마친 결과만 게시한다. 이전 캐시(displayVersion 1)는 자동 표시하지 않는다.

## 실제 영상 대조

원본 영상의 하단 글자를 직접 확인하고, 기존 실제 60초 탭 녹음(시작 2.687474초)을 재분석했다. 이 영상에서는 다운로드 가능한 한국어 자막을 확보하지 못해 화면 자막 OCR이 교정 근거가 됐다. 특정 영상이나 문구를 조건으로 넣은 치환 규칙은 없다.

| 기존 인식 | 화면 근거로 교정한 결과 |
|---|---|
| 이것은 오시오 / 이불이요? | 이것은 옷이오, 이불이오? |
| 입는 오시예요. 한 번 걸쳐보세요. | 입는 옷이에요. 한 번 걸쳐보세요. |
| 한양의 작은 옷 가게. 뒷편 창고는 현대와 이어져 있었습니다. | 한양의 작은 옷 가게 뒤편 창고는 현대와 이어져 있었습니다. |
| 이렇게 붙으렀는데 속이 빈 것은 아니요? | 이렇게 부풀었는데, 속이 빈 것은 아니오? |

## 검증 범위

- Python 90개, Node 62개 테스트 통과. `uv pip check` 의존성 충돌 없음.
- 별도 Chromium 프로필에 실제 확장을 로드하고, 격리된 YouTube 형태의 검수 페이지에서 다운로드한 실제 원본 영상을 재생했다.
- 실제 영상 픽셀 7장 수집, 분석 중 자막 숨김, 완료 후 교정 문구 표시, 6.3/6.9/7.6초에 동일한 21.5px 유지, 페이지 JavaScript 오류 0건을 확인했다. 화면 폭과 구간 음량이 반영된 값이며 기본 설정은 14px이다.
- 사용자 Chrome은 다른 확장 UI가 열려 자동 조작이 차단되어 현재 창에서 새 탭 녹음이나 재로드는 검증하지 못했다. 위 결과를 사용자 Chrome에서 새로 녹음한 결과로 해석하면 안 된다.

실제 영상·이전 녹음·OCR 원문·화면 검수 이미지는 프로젝트 `work/onsori/source-correction/`에 있고 배포 ZIP에는 포함하지 않는다. 서버 작업 원본은 `runtime/jobs/`에 보존한다.

## 한계

화면 자막이 없거나 작거나 가려지면 교정되지 않을 수 있다. 화면 문구 자체의 오류, 의역 자막, ASR와 크게 다른 문장은 자동으로 해결하지 않는다. 이번 확인은 해당 영상 초반 구간의 기능 검증이며 일반 정확도 보장이 아니다.
