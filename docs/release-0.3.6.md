# 온소리 자막 in YouTube 0.3.6 — 화면 정리와 라이트·다크 모드

## 변경 요약

- 패널, 도구 모음 팝업, 사용 방법, 개인정보 안내 화면이 Chrome의 라이트·다크 모드(`prefers-color-scheme`)를 따릅니다.
- 영상 위 진행 안내는 YouTube 플레이어 조작부처럼 영상 위에 겹치므로 두 모드 모두 어두운 중립색입니다.
- 영상 위 자막의 모양은 바뀌지 않습니다(자막 디자인 설정 그대로).
- 기능, 설정 항목, 영역 순서, 저장 값은 0.3.5와 같습니다.

## 디자인 기준

[unslop](https://github.com/heydamir/unslop)(Damir Sokolovsky, CC BY 4.0)의 징후 목록·토큰·패스 순서와 impeccable의 polish·craft floor 기준을 적용했습니다.

- 제품: YouTube 영상의 대사·음악·효과음을 기기 안에서 접근성 자막으로 만드는 확장
- 성격: 또렷함, 조용함, 정확함
- 세계: YouTube 사이드바 안의 방송 자막 — 중립 그래파이트, YouTube 흰 화면·검은 화면 모두에 녹아드는 톤
- 모먼트: 자막 디자인 미리보기, 분석 진행 막대와 음량계
- 시그니처: 대사·효과음·음악 구분 색 점(자막 색 막대와 같은 색, 라이트 모드에서는 진한 색)
