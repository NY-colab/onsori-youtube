# 「온소리 자막 in YouTube」 0.3.8 · GPU 대사 분석·클라우드 대사 분석

## GPU 대사 분석

그래픽 처리 장치(GPU)를 쓸 수 있는 PC에서는 대사 인식에 대형 모델 Whisper large-v3-turbo를 GPU로 실행합니다.<br>먼저 음악·효과음 분석 모델(AST)로 대사가 들리는 구간을 찾고, 그 구간만 14초 이하로 나눠 대사를 인식합니다.<br>음악만 나오는 구간은 대사 인식에 넣지 않아 "끝끝끝…" 같은 반복 글자와 짧은 잡음 대사가 줄었습니다.<br>GPU를 쓸 수 없는 PC는 0.3.7과 같은 작은 모델(Whisper base)을 CPU로 실행합니다.<br>GPU 분석 중 오류가 나면 녹음 전체를 CPU 모델로 처음부터 다시 분석합니다.

첫 실행 때 GPU용 모델 약 740MB를 내려받습니다.<br>CPU용 모델은 약 170MB입니다.

**평가 영상 결과**(「조선에 롱패딩을 팔았다」 361초, 이 PC의 내장 GPU, 격리 Chromium)

| 항목 | 0.3.4 CPU | 0.3.8 GPU |
| --- | --- | --- |
| 글자 오류율(화면 자막 초안 대비, 공백 제외) | 0.427 | 0.155 |
| 화면 자막과 정확히 같은 묶음 | 2/20 | 8/24 |
| 화면 자막에 없는 대사 줄 | 5 | 6 |
| 전체 분석 시간 | 17분 46초 | 7분 28초 |

(*평가 기준은 화면 자막 OCR 초안이며 사람 청취 확인 전의 참고 수치입니다.)<br>화면 자막에 없는 대사 6줄은 "아", "예" 같은 짧은 감탄사 3줄과 앞 문장 반복 1줄, 인식 오류 1줄, 기호 1줄이었고, 기호만 있는 줄은 이번에 표시하지 않도록 고쳤습니다.

**함께 고친 점**

- 깨진 글자(U+FFFD)가 섞인 결과와 한두 글자가 길게 반복되는 결과는 말하는 속도와 관계없이 버립니다.
- 창마다 만들 수 있는 글자 수에 상한을 둬 반복 출력에 걸리는 시간을 줄였습니다.
- 창 경계에서 잘린 문장 조각("어깨도" → "어깨도 편하세요?")과 바로 뒤에 똑같이 반복된 문장은 하나로 합칩니다.
- 글자 수에 비해 지나치게 긴 대사 구간은 그 안에서 대사가 실제로 들리는 부분으로 줄입니다.

## 클라우드 대사 분석(선택)

온소리 서버가 대사 분석을 제공하면, 기기 내 분석을 켠 뒤 한 번 동의 화면을 보여 줍니다.<br>동의하면 영상 전체 분석 때 소리를 온소리 서버로 보내고, 서버가 외부 AI 업체 DeepInfra에서 대사와 시각을 받아 옵니다.<br>음악·효과음 분석, 원래 자막 대조, 글자 크기 계산은 계속 이 기기에서 합니다.<br>거절하거나 ‘다른 방법’에서 끄면 지금처럼 이 기기에서만 분석합니다.

- 설치마다 서버가 무작위 열쇠를 자동 발급합니다.<br>운영자 토큰은 확장 프로그램에 넣지 않았습니다.
- 설치별 하루 20분, 서버 전체 하루 60분 한도를 둡니다.<br>열쇠 발급은 접속 주소마다 하루 3개까지입니다.
- 한도를 넘거나 서버 오류·기간 종료로 쓸 수 없으면 그 영상의 대사를 이 기기에서 분석하고, 이유를 자막 안내에 남깁니다.
- 새 권한을 추가하지 않았습니다.<br>서버가 확장 프로그램 출처의 요청만 허용(CORS)하고, 확장 프로그램 연결 허용 목록에 서버 주소를 넣었습니다.

(*유료 분석은 DeepInfra 결제와 지출 한도를 설정하기 전까지 서버 설정 `ONSORI_ALLOW_PAID=false`로 꺼 둡니다.)<br>그동안 서버는 `disabled` 상태라 동의 화면이 나타나지 않습니다.

개인정보 안내, 사용 방법, 스토어 등록 문구를 클라우드 선택 기능에 맞춰 고쳤습니다.

## 검증

- 확장 프로그램 Node 검사 149개와 클라우드 Python 검사 51개를 2026-11-04에 실행해 모두 통과했습니다.
- 실제 확장 엔진으로 평가 영상 첫 28초를 두 번 분석했습니다.
  - 서버 `disabled`: 업로드가 거절되자 대사를 이 기기 GPU로 분석하고 "클라우드 대사 분석이 꺼져 있습니다." 안내를 남겼습니다.
  - 서버를 잠시 모의 모드로 바꾼 상태: 열쇠 발급 → 업로드 → 조회 → 결과 반영까지 진행했고, 대사 출처가 `onsori-cloud-speech`로 기록됐습니다.<br>시험 직후 서버를 `disabled`로 되돌렸습니다.
- 서버 외부 경로: 공개 상태 200, 열쇠 발급 201, 열쇠 없는 작업 조회 401, 다른 설치의 작업 404, 운영자 상태 403(n8n 주소만), 확장 프로그램 출처 CORS 허용과 다른 웹사이트 출처 차단을 확인했습니다.
