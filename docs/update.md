# 온소리 0.3.3 업데이트 — 파일 교체 후 ⟳ 한 번

**Chrome의 ⟳는 이미 설치된 파일을 다시 읽는 버튼입니다. GitHub에서 새 파일을 내려받는 버튼은 아닙니다.** 아래 순서대로 하면 기존 확장을 삭제하거나 다시 등록할 필요가 없습니다.

## 1. 새 파일 받기

[온소리 0.3.3 ZIP 다운로드](https://github.com/NY-colab/onsori-youtube/releases/download/v0.3.3/OnSori-Chrome-WebStore-0.3.3.zip)

ZIP을 임시 폴더에 압축 해제합니다. 안에 `manifest.json`, `content.js`, `icons`, `vendor` 등이 보이면 맞는 폴더입니다. GitHub의 **Source code (zip)** 대신 위 확장 ZIP을 받으세요.

## 2. 기존 설치 폴더에 덮어쓰기

진행 중인 온소리 분석을 취소하거나 끝낸 뒤, 새 ZIP 안의 **파일과 폴더 전부**를 Chrome에 등록했던 기존 확장 폴더 안으로 복사합니다. 같은 이름의 파일은 **대상 폴더의 파일 덮어쓰기**를 선택합니다. 기존 폴더 자체는 삭제하거나 이름을 바꾸지 마세요.

- 기존 폴더의 `manifest.json`이 새 파일로 교체되어야 합니다. `extension/extension/manifest.json`처럼 폴더를 한 단계 더 넣지 마세요.
- 설치 위치가 기억나지 않으면 `chrome://extensions` → 개발자 모드 → 온소리 **세부정보**의 압축해제된 확장 경로를 확인합니다.
- 예전 `OnSori-Setup.exe`로 설치했다면 기본 확장 위치는 `%LOCALAPPDATA%\OnSori\extension`입니다. 실제 Chrome에 등록된 경로를 먼저 확인하세요. 상위 OnSori 폴더 전체를 덮어쓰지 않습니다.
- 같은 폴더에서 업데이트하면 Chrome 프로필의 자막·설정을 유지합니다. 중요한 자막은 패널에서 JSON으로 먼저 저장할 수 있습니다.

## 3. 사진 속 ⟳ 버튼 누르기

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. **온소리 자막 in YouTube** 카드 오른쪽 아래, 켜기/끄기 스위치 옆의 **⟳ 새로고침**을 누릅니다. 상단의 ‘업데이트’ 버튼과 다릅니다.
3. 카드 버전이 **0.3.3**인지 확인합니다.
4. 열려 있던 **YouTube 영상 탭도 F5**로 새로고침합니다.

버전이 그대로면 다른 폴더에 복사했거나 폴더가 한 단계 더 들어간 것입니다. Chrome에 등록된 폴더의 `manifest.json`을 확인하세요. 빨간 오류가 남으면 세부 오류 내용을 확인하고 [문제 신고](https://github.com/NY-colab/onsori-youtube/issues)에 알려 주세요. 보안 설정이나 다른 확장 권한을 변경할 필요는 없습니다.

## 예전 Windows 설치형에서 넘어오는 경우

0.3.3은 브라우저에서 분석하므로 별도 Python 서버 실행이 필요 없습니다. 이전에 Windows 로그인 시 분석 서버 자동 준비를 켰다면 기존 설치 안내에 따라 자동 시작을 해제할 수 있습니다. 기존 서버·데이터를 이 업데이트가 임의로 삭제하지는 않습니다. 브라우저 모델은 처음 한 번 새로 다운로드될 수 있습니다.

## 이번 버전에서 달라진 점

- YouTube 전체 오디오 주소 누락과 Chrome HTTP 403 문제를 수정했습니다.
- 6분 1초 테스트 영상에서 재생·탭 녹음 없이 전체 분석과 119개 자막 적용을 확인했습니다.
- 영상 옆 패널의 로딩·확장 화면 충돌을 수정했습니다.
- 자막 X·Y 이동, 새로고침 후 위치 유지, 기본 위치 복원을 실제 Chrome에서 확인했습니다.

음성 인식 오류와 일반적인 배경 음악 묘사는 여전히 나올 수 있습니다. PC 성능에 따라 분석에 오래 걸릴 수 있으며, 모든 YouTube 영상에서 전체 오디오를 가져올 수 있다고 보장하지 않습니다. 전체 분석에서 화면 자막 OCR은 수행하지 않습니다.

Chrome 웹스토어 버전은 아직 공개되지 않았습니다. 향후 웹스토어에 게시하더라도 현재 ZIP 설치가 자동으로 웹스토어 설치로 전환되지는 않습니다.
