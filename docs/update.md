# 「온소리 자막 in YouTube」 v0.4.2 설치·업데이트 안내

**현재 공개 버전은 0.4.2입니다. 일반 사용자는 [Chrome 웹 스토어](https://chromewebstore.google.com/detail/faoookmndmicfapakdnelnepfdcphgkp)에서 설치·업데이트하세요.**

GitHub Releases에 공개된 마지막 확장 ZIP은 **0.3.10(구버전)**입니다. Chrome의 확장 프로그램 **⟳ 새로고침**은 이미 설치한 파일을 다시 읽을 뿐, GitHub에서 새 코드를 다운로드하지 않습니다. **0.3.10 ZIP을 설치하거나 덮어써도 0.4.2로 업데이트되지 않습니다.**

## 1. 웹 스토어 설치 사용자

1. [온소리 Chrome 웹 스토어 페이지](https://chromewebstore.google.com/detail/faoookmndmicfapakdnelnepfdcphgkp)를 확인합니다. 신규 사용자는 **Chrome에 추가**를 누릅니다.
2. 기존 웹 스토어 설치본은 Chrome의 자동 업데이트를 이용합니다. 버전 확인이 필요하면 Chrome 주소창에 **chrome://extensions**를 입력하고, 온소리 카드의 **세부정보**에서 버전을 확인합니다.
3. 업데이트 시 **네이티브 애플리케이션과 통신(nativeMessaging)** 권한 승인을 요청할 수 있습니다. 0.4.x에 추가된 권한으로, PC에 별도 연결 프로그램을 설치하지 않았다면 해당 프로그램을 자동으로 설치하거나 실행하지 않습니다.
4. 버전이 **0.4.2**로 표시되면 열려 있던 YouTube 탭을 새로고침합니다. 업데이트 직후 분석이 연결되지 않으면 영상 탭을 다시 새로고침하세요.

웹 스토어 자동 업데이트 시각은 사용자마다 다를 수 있습니다. 확장 관리 화면에 아직 이전 버전이 보이면 **웹 스토어에서 설치한 확장인지** 먼저 확인하세요. 개발자 모드로 직접 등록한 폴더는 웹 스토어에서 자동 업데이트되지 않습니다.

## 2. 0.3.x ZIP 수동 설치 사용자: 0.4.2로 이동

이전에 압축해제된 확장 폴더로 설치했다면 다음 순서를 권장합니다.

1. 중요한 영상의 자막을 온소리 패널에서 **JSON으로 내보내어 백업**합니다.
2. Chrome의 **chrome://extensions**에서 기존 수동 설치본의 위치·버전을 확인하고, 중복 실행을 피하도록 **기존 설치본을 일시적으로 비활성화**합니다. 백업을 확인하기 전에는 삭제하지 마세요.
3. [Chrome 웹 스토어에서 0.4.2 설치](https://chromewebstore.google.com/detail/faoookmndmicfapakdnelnepfdcphgkp)를 진행합니다.
4. 새로 설치된 온소리를 실행해 기능과 데이터를 확인합니다. 필요한 자막은 지원되는 JSON 가져오기 기능으로 복구해 확인하세요.
5. 문제가 없음을 확인한 뒤 이전 수동 설치본을 정리합니다.

**주의:** 수동 설치본과 웹 스토어 설치본은 확장 프로그램 ID나 Chrome 저장 공간이 다를 수 있습니다. 설정·자막의 **자동 이전을 보장하지 않습니다.** 기존에 저장한 자막은 먼저 백업하세요.

### ZIP 수동 업데이트 방법은 언제 적용하나요?

동일한 수동 설치 폴더에 **해당 버전의 확장 ZIP이 실제로 배포된 경우에만** 기존 폴더에 파일을 덮어쓰고, Chrome 확장 카드의 **⟳**와 YouTube 탭 **F5**를 차례로 누릅니다. 설치 폴더의 **manifest.json**이 새 버전으로 바뀌었는지 확인하세요.

현재 공식 GitHub Releases의 [v0.3.10 ZIP](https://github.com/NY-colab/onsori-youtube/releases/tag/v0.3.10)은 **이전 버전 보관 자료**로, 0.4.2 설치용이 아닙니다. GitHub의 **Source code (zip)** 역시 웹 스토어에 제출한 확장 ZIP과 같다고 가정하지 마세요.

## 3. v0.4.2에서 달라진 점

- **대사 크기에 따른 글자 크기:** 대사 줄 안에서 소리가 큰 부분을 영상의 보통 대사 크기와 비교하여 글자 크기를 더 뚜렷하게 표현합니다. 한 자막을 표시하는 동안 크기는 고정되며, 강도는 5단계로 설정할 수 있습니다. 이전에 저장한 자막도 재분석 없이 새 계산 방식으로 표시됩니다.
- **화자 변경 표시:** 사용자가 **클라우드 소리 분석에 동의한 경우**, Gemini에서 받은 화자 변경 정보를 바탕으로 다른 사람이 말하기 시작하는 대사 앞에 **/ **를 표시합니다. 사람을 잘못 구분하거나 표시를 누락할 수 있습니다. 화자 이름은 자막 및 내보내기 파일에 표시하지 않습니다.
- **0.4.1의 변경:** 클라우드 분석을 제공하는 상황에서 사용자가 기기 내 분석과 클라우드 분석 중 선택할 때까지 자동 분석이 기다리도록 바뀌었습니다.
- **0.4.0 이후의 변경:** 재생 위치에서 1분 단위로 분석하고, 완료된 구간부터 자막을 표시합니다. 최근 **최대 60개 영상, 총 약 40MB(코드상 40,000,000바이트)**까지 영상별로 저장하며, 진행 상태와 분석한 구간을 보관합니다.

자세한 구현·검증 기록: [0.4.2 변경 사항](https://github.com/NY-colab/onsori-youtube/blob/release/0.3.7/docs/release-0.4.2.md) · [개인정보 안내](docs/privacy-browser.md)

## 4. 개인정보 및 권한 확인

기기 내 분석은 기본 제공됩니다. **클라우드 소리 분석에 별도로 동의하면** 영상 오디오와 영상 ID·제목이 온소리 서버로 전송되고, 제공 중인 분석 기능에 따라 DeepInfra 또는 Google Gemini를 거칠 수 있습니다. 0.4.2의 **화자 변경 정보는 Gemini의 소리 분석 결과에 포함**됩니다. **AI 자막 보정**을 별도로 켠 경우에는 인식한 대사 텍스트, 영상 제목, 직전 문맥이 선택한 AI 서비스로 전달될 수 있습니다. 소리와 화면 이미지는 이 보정 요청에 포함하지 않습니다.

0.4.x는 영상별 자막 저장을 위해 **unlimitedStorage**, 선택적 Claude Code 연결 프로그램 통신을 위해 **nativeMessaging** 권한을 사용합니다. 연결 프로그램이 없는 일반 사용자에게 별도 프로그램이나 API 키 설치가 필수인 것은 아닙니다.

## 5. 개발자용 소스 버전 구분

- **GitHub main:** 기존 0.3.10 소스이며, 해당 브랜치의 **extension/manifest.json**도 0.3.10입니다.
- **[release/0.3.7 소스 브랜치](https://github.com/NY-colab/onsori-youtube/tree/release/0.3.7):** 실제 **0.4.2 구현 소스**와 **0.4.2 extension/manifest.json**을 포함합니다.
- **[GitHub Releases](https://github.com/NY-colab/onsori-youtube/releases):** 현재 확인된 마지막 ZIP은 0.3.10입니다. 0.4.2 ZIP 다운로드 주소를 추정해 만들지 않습니다.

**main의 manifest.json 버전 번호만 0.4.2로 변경하지 마세요.** 먼저 해당 브랜치에 0.4.2 구현 소스와 필요한 권한·빌드 결과를 맞춘 뒤 매니페스트를 동기화해야 합니다. 그렇지 않으면 실제 기능은 0.3.10인데 버전만 0.4.2로 표시됩니다.

오류와 문의는 [GitHub Issues](https://github.com/NY-colab/onsori-youtube/issues)에 남겨 주세요.
