# 완료 후 표시와 구간별 고정 크기 — 2026-10-25

새 분석 중에도 이전 캐시를 재생하던 문제를 수정했다. 녹음 준비부터 최종 분석이 끝날 때까지 해당 영상의 온소리 자막은 숨긴다. 준비 완료 표시가 없는 이전 캐시, 오디오 미분석 스크립트, 취소·실패한 작업의 이전 결과는 자동으로 표시하지 않는다. 완료 결과와 작업 완료 상태를 하나의 저장 작업으로 게시한다. 수동 JSON 가져오기는 별도의 명시적인 문서 선택이다.

글자 크기는 서버가 이미 계산하는 cue.scale을 사용한다. 이 값은 구간 전체의 RMS와 녹음 공통 기준 음량의 차이로 산출한다. 100ms volume_profile의 순간 배율을 재생 중 적용하던 코드를 제거했다. 따라서 같은 대사·효과음·음악 구간은 크기가 일정하며, 서로 다른 구간의 음량 차이는 유지된다. 화면 크기 변경과 넘침 방지용 맞춤 축소는 유지한다.
