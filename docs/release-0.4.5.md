# 「온소리 자막 in YouTube」 0.4.5 · 자막 직접 수정 모드

## 바뀐 동작

- 조작 창에 **자막 직접 수정 모드**를 추가했습니다(기본 꺼짐).<br>켜면 영상 위 자막에 점선 테두리가 생기고, 영상 오른쪽 위에 ‘지금 자막 고치기’ 버튼이 나타납니다.
- 자막이나 이 버튼을 누르면 영상이 멈추고, 그 순간 화면에 나온 자막을 고치는 창이 영상 위에 열립니다.<br>화면에 자막이 없으면 바로 앞 자막을 엽니다.
- 수정 창에서 글을 고치고 Enter나 ‘저장’을 누릅니다.<br>‘이 자막 숨기기’로 자막을 빼고, 고친 자막은 ‘원래대로’로 분석 결과로 되돌립니다.<br>‘이전 자막·다음 자막’으로 영상을 옮겨 가며 이어서 고칩니다. Esc로 닫습니다.
- 고친 자막은 이 Chrome 프로필의 `chrome.storage.local`(`ed:<영상 ID>`)에만 저장하고 다른 곳으로 보내지 않습니다.
- 분석 결과와 따로 보관하고 표시할 때 덮어씌웁니다.<br>1분 단위 분석이 이어지거나 다시 분석해도 같은 자막(같은 ID, 또는 같은 종류·같은 원문·시작 2초 이내)에 다시 적용됩니다.
- 조작 창에 고친 자막 수와 ‘고친 자막 모두 되돌리기’를 표시합니다.<br>‘이 영상의 자막 지우기’는 고친 자막도 함께 지웁니다.
- ‘JSON 저장’ 파일에는 고친 자막이 들어가고, 고치기 전 문장을 `user_edit.original_text`로 남깁니다.
- 권한과 외부로 보내는 데이터는 0.4.4와 같습니다.

## 확인 결과

- 확장 검사 200개를 2026-11-28에 실행해 모두 통과했습니다.<br>바꾸기·숨기기·되돌리기, 다시 분석 뒤 다시 적용, 내보내기 기록, 고칠 자막 고르기 검사 4개를 더했습니다.
- 시험용 Chromium에 확장을 설치해 실제 YouTube 영상(jpQQ9WveNZA)에서 확인했습니다(`browser-build/qa-edit-mode.mjs`).<br>자막을 누르면 영상이 멈추고 수정 창이 열렸고, 「금니가 올랐습니다」를 「금리가 올랐습니다」로 고쳐 저장하자 바로 화면에 반영됐습니다.<br>‘다음 자막’으로 9.05초의 효과음 자막으로 넘어갔고, 새로고침 뒤에도 고친 자막과 조작 창 표시가 유지됐습니다.

## 알려진 한계

- 자막 내용만 고칩니다. 자막이 나오는 시각은 아직 바꿀 수 없습니다.
- 숨긴 자막은 화면에서 다시 누를 수 없어, 조작 창의 ‘고친 자막 모두 되돌리기’로만 되살립니다.
